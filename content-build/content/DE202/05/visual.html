1. Two Ways To Watch

You already know both of these shapes. Query-based CDC is the high-water mark from lesson 2, pointed at a source table. Log-based CDC is the event stream from lesson 4, produced by a database that never meant to emit one. Tap either. Like reading a shop's till roll versus counting the shelves each morning.

2. What Polling Misses

An order row changes three times between two polls. Drag the poll interval and watch which transitions reach the consumer. Like a security camera that only takes a photo every hour.

This is not a tuning problem you can poll your way out of — shortening the interval reduces the odds, never the possibility. If a downstream consumer genuinely needs the intermediate state, polling is the wrong mechanism, not a mis-tuned one.

3. The Version Guard

Four events for customer C42, arriving out of order — including a delete. Apply them with and without a per-key version guard. Like refusing to file a document stamped older than the one already in the folder.

The guard does two jobs at once: it fixes ordering and makes redelivery idempotent, because a duplicate carries a version that is not newer. That is effectively-once from lesson 4, expressed as one comparison.

4. Snapshot Handoff

A new consumer needs baseline state before the live stream is useful. Step through the handoff and see which failure each choice causes. Like photographing a whiteboard while someone is still writing on it.
