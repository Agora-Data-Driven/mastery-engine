1. The Provenance Chain

Training-Serving Skew ended on an invariant: reproduce the values and versions the model actually received. That needs a chain from the deployed model back to immutable bytes. Tap a link to see what it must resolve to — then break one. Like a receipt that names the shop, the till and the exact item, not just "groceries".

Rollback needs a compatible pair

Versioning does not mean copying bytes. Snapshot-aware tables share unchanged files across versions, content-addressed objects deduplicate, and a manifest can reference features that already exist. Logical immutability and durable reachability matter more than physical duplication.

2. Recipe Or Ingredients

The same SQL, three months apart. Nothing about the query changed and four normal things happened to the tables underneath it. Press replay. Like re-cooking from a recipe after someone has restocked the fridge.

Randomness belongs in the contract too: record the split algorithm, the seed, the grouping keys and the deterministic ordering. Hash-based splits on a stable entity ID reproduce better than pseudorandom row ordering, and a library upgrade can change the sequence a numeric seed produces even when nothing else moved.

3. One Coherent Cut

Three input tables, each publishing on its own cycle. Letting every task grab "latest" builds a dataset from three different moments — coherent-looking, and never actually true at once. Drag the task start times apart. Like a group photo assembled from three snapshots taken minutes apart.

And pinning a snapshot is not point-in-time correctness. A run replaying March examples against today's pinned feature tables can still use values unknown in March — the snapshot must contain temporal history, and the join must still enforce each example's cutoff. Two independent requirements that are constantly mistaken for one.

4. How Identical Is Identical

You rebuild the dataset from its lineage in a clean environment. The output differs. Is that a bug? It depends entirely on which level of reproducibility you claimed. Pick a level. Like "the same recipe": same dish, same weights, or the same molecules?

The four-level diff — because one checksum explains nothing

Run rebuild drills on important deployed models instead of waiting for an incident. A drill exposes expired snapshots, unavailable containers, revoked credentials, undocumented manual inputs and dependency registries that no longer retain artifacts. Recovery documentation is credible only when the path still executes.
