1. From Load To Transform

Pub/Sub, Dataflow and Datastream filled the warehouse; partitioning and clustering and materialized views made it cheap to read. This lesson is the band in the middle. Tap a stage to see who owns it and which lesson taught it. Like a kitchen: deliveries, cold store, prep bench and pass are different jobs, and the head chef calls the order without cooking.

The band is not a fifth processing engine. An orchestrator should start work, pass small parameters, observe status, enforce dependencies and record outcomes — never absorb the processing itself. Let BigQuery and Dataform run SQL, Dataflow process distributed data, and Cloud Data Fusion run its integration pipeline. That separation is what gives you clean retries, real scaling and service-specific monitoring.

2. The Dependency Graph

Calling ref on an upstream object both qualifies its name and declares the edge, so Dataform compiles an ordered graph instead of a list. Switch how the same five build steps are wired and watch the wall clock move. Like cooking a roast dinner: the potatoes do not have to wait for the gravy just because the recipe printed them in that order.

The assertion is part of the graph on purpose. A built-in check for uniqueness or non-null values, or a custom SQL test like revenue >= 0, is a data contract: a failure is not a cosmetic warning, it means downstream consumers are about to be served data whose promise is known to be broken. Place the check beside the model whose promise it protects, name it usefully, and route the failure to an owner.

3. Compile Then Execute

Dataform has two phases and they fail for completely different reasons. Compilation is hermetic — no arbitrary internet calls, identical inputs intended to give identical SQL. Execution is BigQuery doing the work. Tap a defect and watch which box it lands in. Like proof-reading a recipe versus burning the dinner: one is caught at the desk, the other only at the stove.

4. Fusion Run Modes

In Cloud Data Fusion the logical pipeline says what should happen and the compute profile says where and with what resources it runs. Switch the profile and notice what does not move. Like a play: the same script can be staged in a rented hall for one night or in a theatre you keep year-round.

Awareness level means: recognise Cloud Data Fusion as the visual, connector-rich integration option built on the open-source CDAP project, then check whether its abstraction matches the workload. Dataform is the more direct fit for SQL that stays in BigQuery; Dataflow gives code-centred, fine-grained batch and streaming through Apache Beam; Datastream specialises in managed CDC; and unusually specialised logic may simply want a custom application.

5. Airflow Or Workflows

The choice is not Python versus YAML. Begin with operating model and workload shape. Toggle the requirements that are actually true of your process and read the selection statement it produces. Like hiring a full-time head chef or booking caterers per event — both can serve dinner; only one of them is on your payroll all year.

Whichever you pick, make every task idempotent. A retry can happen after a remote action succeeded but before the orchestrator recorded that success, so pass stable operation IDs, check existing state, and make create-or-update explicit. Keep large data outside orchestration variables, grant the runtime identity only the permissions it needs, bound retries for transient failures, and send permanent failures to an actionable alert or recovery path.
