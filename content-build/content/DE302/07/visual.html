1. Five Control Questions

Dataplex described the data, Analytics Hub handed it to someone else, BigLake put one access layer over storage you do not own the format of, and Dataflow filled all of it. None of them asked who may act, under which key, on which fields, in which country, inside which boundary. Tap something you already built and see the five questions it forces. Like a finished building: the walls are up, and now someone asks who holds the keys, which rooms are locked and which country the plans are stored in.

The five mechanisms answer different questions, and most wrong answers are a correct mechanism aimed at the wrong one. IAM decides whether a principal is authorized to request an action; Organization Policy can still reject the resulting configuration; Cloud KMS controls the key; Sensitive Data Protection controls the values; the hierarchy decides how few times you have to say any of it. Security is an architectural property, not a checklist bolted on after a pipeline works.

2. Grant At Which Level

A role is a set of permissions; the attachment point decides what it touches, because grants inherit to every descendant. Pick a role and a level and watch the blast radius move across an estate of 12 resources. Like handing over a key: the same key cut for the front door, the floor or one office opens wildly different amounts of building.

Two things this panel cannot draw. Organization Policy answers second: IAM may authorize the request and a location or key-creation constraint still rejects the resulting configuration. And labels are not security boundaries — they are inventory and cost reporting. The boundary is the folder, the project and above all the dataset.

3. Envelope And Rotation

Default encryption is real encryption; CMEK is about control. Twelve months of data, each batch wrapped by whichever key version was primary when it was written. Rotate, disable and destroy, and watch which months you can still read. Like a safe-deposit box: rotating the lock does not reopen last year's boxes — you still need the old key to open those.

A key ring is a regional container, a crypto key expresses purpose and policy, and key versions hold the material — keep the key location compatible with what it protects. Grant the service's encryption identity only encrypt and decrypt while limiting who may administer keys. Autokey, Cloud HSM and Cloud EKM each add cost and failure modes: the best key architecture is the least complex one that meets the real control objectives.

4. Choose The Transform

Sensitive Data Protection finds values with detectors called infoTypes, then de-identifies them. The transform is not a security setting — it is chosen from the analytical purpose. Pick a field and a transform and read the three verdicts. Like redacting a document: a marker, a sticker, a summary and a code name all hide the name, and only one of them lets you still count how often it appeared.

Two things people forget. Findings are themselves sensitive — a finding carries location, type, likelihood and sometimes contextual material, so restrict who can read them and choose output destinations deliberately. And discovery locates risk without remediating it or proving every sensitive value was found: run the loop — discover, classify, transform or restrict, verify, monitor — because new sources and schema drift reintroduce PII.

5. Trace The Path

Choosing a region is necessary and nowhere near sufficient. Ten things carry your data, and the claim is only as strong as the weakest one. Tap each to move it inside the boundary and watch what you are entitled to say. Like claiming nobody leaves the house: the front door is not the argument if there is a back door, a window and a bin collection.

Residency is a location; sovereignty is the regime. Residency says where data is stored or processed; sovereignty asks which laws, authorities, operational controls and organizational obligations govern it. Legal and compliance owners interpret the obligation; architects translate it into enforceable controls and evidence. Avoid absolute claims such as "no data ever leaves the country" unless the entire system and its operational processes can prove them.
