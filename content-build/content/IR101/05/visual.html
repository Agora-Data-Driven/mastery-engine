1. From Postings To Gaps

You already keep postings in increasing document-ID order — that is what makes Boolean Query Processing by Intersecting Postings a two-cursor walk and what lets Skip Pointers jump. This lesson charges for those bytes and takes the ordering as payment: keep the first ID, store only differences afterwards. Drag the corpus and the term's density. Like giving directions as "third door on the left" instead of a full street address.

Decoding is a prefix sum, so the intersection you already know still sees absolute IDs — nothing above the codec changes. What does change is the invariant: sorted order stopped being a convenience and became part of the format. Break it and a gap goes negative, which most postings codes cannot represent at all.

2. Decoding The Gap Stream

One stream carries document gaps, term frequencies and position gaps, and only a running accumulator tells them apart. Step through it — then break it two ways and watch what the damage costs. Like a treasure hunt where each clue gives the next step, not the destination: one wrong clue and everything after it is in the wrong place.

This is why blocks carry restart points and checksums: they bound the blast radius of a single bad gap, and they give a decoder a known absolute base to re-enter at. Build tests that check monotonicity and decoded counts catch the other failure before it ever ships.

3. Seven Bits Per Byte

Variable-byte writes an integer in base 128 and spends one bit of every byte saying "keep going" or "that was the last one". Move the value and watch the byte count step rather than slide. Like paying in whole coins: the price jumps at the coin, never between two of them.

The decode loop is four steps: read a byte, accumulate its seven payload bits, emit if the marker says terminal, and — for postings — add the emitted gap to the previous document ID. Polarity is a choice: a reader expecting terminal-high-bit cannot read continuation-high-bit data, and the bytes decode into plausible garbage rather than failing loudly. Hence version metadata and golden vectors.

4. Ratio Versus Latency

Four codecs over the same block of 128 gaps. Smallest does not mean fastest, and the winner changes with where the bytes live and what you are paying for. Like vacuum-packing a suitcase: brilliant for the airline’s scales, miserable if you need one shirt at every stop.

The other 127 gaps average 10 — four bits each — throughout. Nothing about the data changes as you drag; only the single outlier and the codec’s reaction to it. That is the whole reason the lesson says to measure the gap distribution per term and per block, not just the average.

5. Postings Or Parquet

The same four numbers, the same three transforms, two different systems. Flip the system to see how each line changes, then pick a workload and see which codec the difference actually argues for. Like the same recipe cooked for a restaurant service and for a freezer: identical ingredients, opposite priorities.

Sortedness is the one lever that pays on both sides at once: document order is required for intersection and happens to create small gaps, while sorting a Parquet column tightens min/max statistics, creates runs and shrinks deltas. One write-time decision, two systems, the same benefit — which is exactly why this topic is a bridge rather than a coincidence.
