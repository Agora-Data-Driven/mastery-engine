2. Contract At Each Stage

A real funnel is five stages, not two, and each arrow between them is a contract: input width, output width, score meaning, timeout, fallback, filters, IDs. Tap a stage to read its contract and what a lost document looks like there. Then turn off the diagnostic trace and watch attribution die. Like a relay handover — the baton has to be passed the same way every lap, or nobody can say who dropped it.

Two rules run the whole strip. Authorization belongs before expensive scoring — a reranker handed unauthorized text has already crossed a security boundary even if the interface hides the result — and a fallback is a mode, not an exception handler: it is separately evaluated, it logs which path served, and it still enforces the same access rules.

3. The Depth Frontier

Budgeting candidates per stage means working backward from the objective: pick the quality floor, pick the latency allocation, then take the smallest depth that clears both. Drag the allocation and watch which rows survive — and watch what each extra candidate is actually buying. Like packing for a flight: the answer is the lightest bag that still holds everything you need.

Quality floor — candidate success@k

Depth is not the only budget in this stage. A reranker with maximum sequence length L must split tokens between query and document, so fifty 2,000-token documents are not fifty 200-token passages — truncation and batching differ, and relevance evidence can sit outside the retained span. Chunk upstream, truncate deterministically, and measure how often that happens.

4. What Eats The Budget

A budget written on a diagram is not the budget you get. Three things bend it: sources overlap, filters run late, and per-request depth multiplies into fleet size. Switch between them and move the dials. Like a shopping list that survives contact with the shop — two aisles sell the same thing, half the shelf is out of stock, and everything is per person.

All three are reasons the offline sweep is only the start. Online, log requested and actual depth, source contribution, unique union size, filter attrition, tokens, batch count, model time and queue time — then revisit the budget whenever the corpus, the retrievers, the filters, the hardware or the precision model changes, because every one of those moves the funnel's operating point.
