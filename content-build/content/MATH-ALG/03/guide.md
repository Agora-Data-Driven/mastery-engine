**The big idea**: **Intercepts and Slope**, **Slope-intercept form, Point-slope form, and Standard form**, and **Parallel and perpendicular lines** gave you a line three ways, and **Modeling with linear equations** read $m$ as a rate and $b$ as a starting amount. Throughout, $y$ was quietly being treated as something *produced by* $x$. This lesson names that relationship and drops the requirement that it be a line. A **function** is a rule assigning to each input exactly one output; everything else here is a question you can ask about such a rule. Is it one at all (**Recognizing functions from tables and graphs**)? What does it return (**Evaluating functions and function notation**)? What is allowed in and what comes out (**Domain and range**)? Where does it sit above or below the axis, and where is it climbing (**Intervals (Positive/Negative, Increasing/Decreasing)**)? Can it be run backwards (**Introduction to inverse functions**)?

**Key concepts**

- **Recognizing functions from tables and graphs is one criterion applied to two representations: each input is paired with exactly one output.** In a table, look for a repeated $x$ whose $y$ values disagree: a table pairing $x = 2$ with both $y = 5$ and $y = 7$ is **not a function**, since no rule can return both. On a graph it becomes the **vertical line test**: a vertical line is the set of all points sharing one $x$, so a curve meeting one twice gives that $x$ two outputs. A circle fails it — on $x^2 + y^2 = 25$ the input $x = 0$ maps to $y = 5$ and $y = -5$ — not its radius, not its intercepts. Conversely $y = |x|$ **passes** the vertical line test: $x = -3$ returns $3$ and only $3$. It is also symmetric about the $y$-axis and it is defined piecewise, but neither fact is why it qualifies. Repeats in the *output* are legal: $f(-3) = f(3) = 9$ costs $x^2$ nothing.
- **Evaluating functions and function notation: $f(x)$ is an instruction, not a product.** To evaluate, substitute the given input for **every** occurrence of $x$ and simplify. $f(x) = 2x + 1$ gives $f(3) = 2(3) + 1 = 7$. $g(x) = x^2 - 4$ gives $g(-2) = (-2)^2 - 4 = 4 - 4 = 0$ — the parentheses are load-bearing, since $-2^2 = -4$ is a different computation, giving $-8$. $h(x) = 1/(x - 2)$ gives $h(5) = 1/3$ — the whole denominator is evaluated first — not $3$ or $1/5$.
- **The input can itself be an expression, and that is where notation errors live.** $f(-x)$ means "run $f$ with input $-x$", so you replace $x$ by $-x$ throughout: $f(-x) = 2(-x) + 1 = -2x + 1$. The commonest error is leaving $x$ unchanged somewhere in the formula, which silently computes $f(x)$ instead. Likewise $f(a + h)$ is the output of $f$ when the input is $a + h$ — not $f(a) + h$, not $f(a)$ times $h$. With $f(x) = 2x + 1$: $f(a + h) = 2(a + h) + 1 = 2a + 2h + 1$, while $f(a) + h = 2a + 1 + h$. Those agree only when $h = 0$ — and $f(a+h)$ is the numerator of the difference quotient from calculus.
- **Domain and range: the domain is the set of possible inputs, the range is the set of possible outputs.** Exactly two things shrink a domain here. A zero denominator: $f(x) = 1/(x - 3)$ is defined for **all real numbers except $x = 3$**, the one input making the denominator zero — a single puncture, not a half-line. An even root of a negative: $f(x) = \sqrt{x - 2}$ needs $x - 2 \geq 0$, so the domain is $x \geq 2$, with $x = 2$ **included** since $\sqrt{0} = 0$ is defined.
- **Range is answered by asking which $y$ are actually hit.** For $y = x^2$: a square is never negative, so no $y < 0$ is attainable, every $y \geq 0$ is attained by $x = \sqrt{y}$, and $y = 0$ at $x = 0$. The range is therefore $y \geq 0$, not $y > 0$: the boundary belongs, and that is the entire difference between two answer choices. A linear $f(x) = 2x + 1$ has domain and range all of $\mathbb{R}$.
- **Intervals (Positive/Negative, Increasing/Decreasing) are two independent questions, and the topic is built on people conflating them.** *Sign* is about the value of $f$: $f(x) < 0$ on an interval means the graph lies **below the $x$-axis** there, and conversely: below the axis is exactly what "negative" means, above it is positive. To find where a function is positive from its graph, look for $x$-values where the output $y$ is greater than zero — not where $x$ is positive, not where the slope is zero. *Direction* is about how $f$ changes: $f$ is **increasing** on an interval when its output values become larger as $x$ moves left to right, the graph rises from left to right, i.e. $f'(x) > 0$ throughout.
- **Worked slowly.** $f(x) = x^2 - 4 = (x-2)(x+2)$ is negative exactly between its roots, on $(-2, 2)$; identically, $f(x) = x^2 - 9$ is negative on $(-3, 3)$. Direction on that same interval: $f'(x) = 2x$, so on $(-2, 0)$ it is below the axis **and decreasing**, on $(0, 2)$ still below the axis **and increasing**. One sign, two directions. And $f(x) = x^3$ has $f'(x) = 3x^2 \geq 0$, zero only at the single point $x = 0$, so it is **increasing for all $x$** — yet negative for every $x < 0$: "increasing everywhere" and "positive everywhere" are unrelated claims. For $f(x) = -x^2 + 4x$, $f'(x) = -2x + 4 > 0$ exactly when $x < 2$, so $f$ is increasing on $(-\infty, 2)$; the same derivation on $f(x) = -x^2 + 6x$ gives $f'(x) = -2x + 6$ and increasing on $(-\infty, 3)$.
- **A sign change forces a crossing.** If a continuous $f$ is negative just left of $x = 2$ and positive just right of it, the intermediate value theorem says it takes the value $0$ there: $x = 2$ is an $x$-intercept. It need not be a local minimum — the function is rising *through* the axis, not turning — and a continuous function has no vertical asymptote.
- **Introduction to inverse functions: forming the inverse interchanges the roles of the inputs $x$ and the outputs $y$.** No algebra is needed to read one value: if $f$ is invertible and $f(3) = 8$, then $f^{-1}(8) = 3$ — the same arrow, backwards. Because $(a, b)$ on $f$ becomes $(b, a)$ on $f^{-1}$, and swapping coordinates is reflection across the line $y = x$, the two graphs are **mirror images across $y = x$** (not $y = 0$, not $x = 0$, not $y = -x$). Domain and range trade places for the same reason.
- **The inverse of a function is a function only if the original is one-to-one.** Reversal turns outputs into inputs, so an output reached from two inputs becomes an input with two outputs — the one thing a function may not have. The graph test is the **horizontal line test**: a horizontal line is the set of points sharing one $y$, so a curve meeting one twice makes the inverse fail the vertical line test. $f(x) = x^2$ fails it on all reals ($y = 9$ at $x = \pm 3$); restricted to $x \geq 0$ it passes. Worked: $f(x) = 2x + 1$ is one-to-one, and solving $y = 2x + 1$ gives $x = (y-1)/2$, so $f^{-1}(x) = (x-1)/2$ and $f^{-1}(7) = 3$, matching $f(3) = 7$. Note that $f^{-1}$ is not a reciprocal: $f^{-1}(8) \neq 1/f(8)$.

**Rules to remember**

- Function ⟺ each input is paired with exactly one output. Repeated outputs are fine; repeated inputs with different outputs are fatal.
- Vertical line test ⇒ is it a function. Horizontal line test ⇒ is its inverse a function. Different lines, different questions.
- Substitute the input for **every** $x$, in parentheses. $g(-2) = (-2)^2 - 4 = 0$.
- $f(a + h)$ is one evaluation at the input $a + h$; it is not $f(a) + h$ and not $f(a) \cdot h$.
- Domain = possible inputs, range = possible outputs. Denominators may not be zero; even radicands may not be negative.
- The range of $x^2$ is $y \geq 0$: the endpoint is attained, so the inequality is not strict.
- $f(x) < 0$ ⟺ graph below the $x$-axis. $f'(x) > 0$ ⟺ increasing ⟺ rises left to right.
- Sign and direction are independent: $x^3$ is increasing everywhere and negative on $(-\infty, 0)$.
- A continuous function changing sign at a point has an $x$-intercept there.
- The inverse reflects the graph across $y = x$, and exists as a function exactly when $f$ is one-to-one.

**Common pitfalls**

- Rejecting a table because its $y$ values repeat. Only a repeated $x$ with disagreeing $y$ matters.
- Justifying "$y = |x|$ is a function" by its symmetry, its piecewise definition, or the horizontal line test. The reason is the vertical line test.
- Dropping parentheses on a negative input: writing $-2^2 = -4$ instead of $(-2)^2 = 4$.
- Evaluating $f(-x)$ by changing only the first term, or by negating the answer.
- Treating $f(a + h)$ as $f(a) + h$, or as $f(a) cdot h$.
- Excluding $x = 2$ from the domain of $\sqrt{x - 2}$, or writing the range of $x^2$ as $y > 0$. Both are the boundary case, dropped.
- Reading "below the $x$-axis" as "decreasing", or "increasing" as "positive". The confusion runs both ways and is what the distractors are made of.
- Reporting where $x$ is negative instead of where $f(x)$ is negative.
- Reading $f^{-1}$ as $1/f$, or reflecting across $y = -x$ or the $x$-axis instead of $y = x$.

**How to approach the questions**

1. For "is it a function", work from the representation. Table ⇒ look for a repeated $x$. Graph ⇒ sweep a vertical line. Equation ⇒ ask whether one $x$ can produce two $y$, as a circle or $x = y^2$ can.
2. For evaluation, write the substitution out with parentheses before simplifying. Most wrong options answer a *different* substitution ($f(3)$ or $-f(3)$ for $f(-3)$), so producing your own value first makes them harmless.
3. For domain, hunt only for zero denominators and negative even radicands, then state the exclusion the way the options do: "all reals except $x = 3$", or "$x \geq 2$". For range, ask which outputs are reachable and check the boundary separately.
4. For interval questions, decide in one beat whether the question is about **sign** or about **direction**. "Below the axis", "negative", "$f(x) < 0$" are sign. "Rises", "increasing", "$f'(x) > 0$" are direction. Half the options will answer the other question.
5. To get a sign interval fast, factor and use the roots: $x^2 - 9$ is negative strictly between $-3$ and $3$. To get a direction interval, differentiate and solve the inequality: $-2x + 6 > 0$ gives $x < 3$.
6. For inverse questions, read the arrow backwards before doing algebra: $f(3) = 8$ answers $f^{-1}(8)$ at once. The two graph facts are reflection across $y = x$ and the horizontal line test for one-to-one.
