### Multiplying binomials and special products

- Q: Which of the following special-product identities is correct?
    [ ] $(a + b)(a - b) = a^2 + 2ab + b^2$
    [ ] $(a - b)^2 = a^2 - b^2$
    [ ] $(a + b)^2 = a^2 + b^2$
    [CORRECT] $(a + b)^2 = a^2 + 2ab + b^2$
- Q: Expand the square $(x - 4)^2$.
    [ ] $x^2 + 8x + 16$
    [ ] $x^2 - 16$
    [CORRECT] $x^2 - 8x + 16$
    [ ] $x^2 - 4x + 16$
- Q: When squaring a binomial such as $(a + b)^2$, what is the most common mistake?
    [CORRECT] Omitting the middle term $2ab$
    [ ] Applying the FOIL method
    [ ] Combining the like terms
    [ ] Squaring each coefficient
- Q: Expand the product $(x + 3)(x + 5)$.
    [ ] $x^2 + 15x + 8$
    [CORRECT] $x^2 + 8x + 15$
    [ ] $x^2 + 2x + 15$
    [ ] $x^2 + 8x - 15$
- Q: Expand the product $(2x + 1)(2x - 1)$.
    [ ] $2x^2 - 1$
    [ ] $4x^2 + 1$
    [CORRECT] $4x^2 - 1$
    [ ] $4x^2 - 2x + 1$

### Factoring quadratics (intro, grouping, difference of squares, perfect squares)

- Q: What is a useful first step when factoring any polynomial?
    [ ] Square each individual term
    [CORRECT] Check for a greatest common factor
    [ ] Multiply all the coefficients
    [ ] Set the polynomial equal to 1
- Q: What is the complete factorization of $x^2 - 9$?
    [ ] $(x - 9)(x + 1)$
    [CORRECT] $(x - 3)(x + 3)$
    [ ] $(x + 3)^2$
    [ ] $(x - 3)^2$
- Q: Which of the following expressions is a difference of squares?
    [CORRECT] $x^2 - 9$
    [ ] $x^2 + 6x + 9$
    [ ] $x^2 + 9$
    [ ] $x^2 - 6x + 9$
- Q: Factor by grouping: $x^3 + 3x^2 + 2x + 6$.
    [CORRECT] $(x + 3)(x^2 + 2)$
    [ ] $(x + 6)(x^2 + 1)$
    [ ] $(x + 2)(x^2 + 3)$
    [ ] $(x^2 + 2)(x^2 + 3)$
- Q: What is the complete factorization of $x^2 + 6x + 9$?
    [ ] $(x - 3)^2$
    [ ] $(x + 9)(x + 1)$
    [ ] $(x + 6)(x + 3)$
    [CORRECT] $(x + 3)^2$
