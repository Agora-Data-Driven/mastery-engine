### Exponent properties (integer exponents)

- Q: For a nonzero base $x$, the power $(x^m)^n$ simplifies to:
    [ ] $x^{m-n}$
    [ ] $m \cdot x^n$
    [ ] $x^{m+n}$
    [CORRECT] $x^{mn}$
- Q: For a nonzero base $x$, the product $x^m \cdot x^n$ simplifies to:
    [ ] $x^{mn}$
    [ ] $x^{m-n}$
    [ ] $(x+m)^n$
    [CORRECT] $x^{m+n}$
- Q: For $x \neq 0$, the expression $x^{-2}$ is equal to:
    [ ] $x/2$
    [ ] $2/x$
    [CORRECT] $\frac{1}{x^2}$
    [ ] $-x^2$
- Q: For any nonzero $x$, the value of $x^0$ is:
    [ ] $x$
    [CORRECT] $1$
    [ ] undefined
    [ ] $0$
- Q: For $x \neq 0$, the quotient $\frac{x^m}{x^n}$ simplifies to:
    [ ] $x^{n-m}$
    [ ] $x^{m+n}$
    [CORRECT] $x^{m-n}$
    [ ] $x^{mn}$

### Simplifying square-root expressions

- Q: Written in simplest radical form, $\sqrt{50}$ equals which of the following?
    [CORRECT] $5\sqrt{2}$
    [ ] $10\sqrt{5}$
    [ ] $25\sqrt{2}$
    [ ] $2\sqrt{5}$
- Q: To simplify a square root, the key step is to factor the radicand so you can pull out:
    [ ] the denominator
    [ ] a single prime
    [ ] an odd factor
    [CORRECT] a perfect square
- Q: Over the real numbers, the rule $\sqrt{ab} = \sqrt{a} \cdot \sqrt{b}$ is guaranteed to hold precisely when:
    [ ] a equals b exactly
    [ ] a plus b equals zero
    [CORRECT] a and b are both nonnegative
    [ ] a and b are both negative
- Q: Which expression simplifies to exactly $3\sqrt{2}$?
    [ ] $\sqrt{24}$
    [CORRECT] $\sqrt{18}$
    [ ] $\sqrt{12}$
    [ ] $\sqrt{6}$
- Q: Combining like radicals, $2\sqrt{3} + 5\sqrt{3}$ equals which of the following?
    [CORRECT] $7\sqrt{3}$
    [ ] $7\sqrt{6}$
    [ ] $10\sqrt{3}$
    [ ] $3\sqrt{8}$

### Graphing exponential growth and decay

- Q: For $y = b^x$ to model exponential decay, the base $b$ must be:
    [ ] exactly equal to 1
    [ ] negative only
    [CORRECT] between 0 and 1
    [ ] greater than 1
- Q: As $x$ increases, the graph of an exponential growth function $y = b^x$ ($b > 1$) tends to:
    [CORRECT] rise ever more steeply
    [ ] drop down toward 0
    [ ] hold a constant value
    [ ] straighten into a line
- Q: For $y = b^x$ to model exponential growth, the base $b$ must be:
    [ ] between 0 and 1
    [CORRECT] greater than 1
    [ ] negative only
    [ ] exactly equal to 0
- Q: For the exponential function $y = b^x$ with $b > 0$, the y-intercept is always:
    [ ] $0$
    [ ] $b$
    [ ] $1/b$
    [CORRECT] $1$
- Q: Which of these functions represents exponential decay?
    [ ] $y = x^3$
    [ ] $y = 3x + 1$
    [CORRECT] $y = (\frac{1}{3})^x$
    [ ] $y = 2^x$
