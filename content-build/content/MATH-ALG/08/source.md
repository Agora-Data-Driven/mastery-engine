### Reducing, multiplying, and dividing rational expressions

- Q: After simplifying a rational expression by canceling common factors, which domain restrictions must still be stated?
    [ ] Only those arising from the numerator
    [ ] Only those visible in the simplified expression
    [ ] None, since simplifying removes all restrictions
    [CORRECT] Those coming from the original denominator
- Q: Divide $\frac{x^2 - 1}{x + 2}$ by $\frac{x - 1}{x + 2}$ and simplify.
    [ ] $x - 1$
    [ ] $\frac{x^2 - 1}{x - 1}$
    [ ] $\frac{x + 1}{x - 1}$
    [CORRECT] $x + 1$
- Q: Simplify $\frac{x^2 - 16}{x^2 - 4x}$.
    [CORRECT] $\frac{x + 4}{x}$
    [ ] $\frac{x + 4}{x - 4}$
    [ ] $\frac{x - 4}{x + 4}$
    [ ] $\frac{x - 4}{x}$
- Q: The expression $\frac{x^2 - 9}{x - 3}$ simplifies to $x + 3$, but only with the restriction $x \neq 3$. Why must that restriction be stated?
    [ ] The simplified form $x + 3$ turns out to be undefined when $x = -3$
    [ ] The numerator $x^2 - 9$ cannot in fact be factored at all
    [CORRECT] Canceling drops the factor that made the original denominator zero at $x = 3$
    [ ] Two equivalent expressions are required to share an identical numerator
- Q: Why may you cancel something only when it is a factor of the whole numerator and the whole denominator?
    [CORRECT] Because canceling is really just division, so only shared common factors are removed
    [ ] Because rational expressions just do not behave like ordinary numeric fractions do
    [ ] Because individual added terms inside an expression can simply never be divided at all
    [ ] Because the denominators of these rational expressions generally cannot be factored
- Q: Multiply $(\frac{2x}{3}) \times (\frac{9}{x^2})$ and simplify.
    [CORRECT] $\frac{6}{x}$
    [ ] $\frac{3}{x}$
    [ ] $6x$
    [ ] $\frac{18}{x^2}$

### Adding and subtracting rational expressions

- Q: Why is 1/(x+1) + 1/(x-1) not equal to 2/(2x)?
    [ ] Two algebraic fractions can never be added together at all
    [ ] The denominators may be added only when the numerators match
    [CORRECT] A common denominator is needed before the fractions combine
    [ ] The variable x must first be canceled from each of the terms
- Q: Simplify 1/x + 1/2.
    [ ] 2/(x + 2)
    [CORRECT] (x + 2)/(2x)
    [ ] (x + 1)/2
    [ ] 1/(2x)
- Q: Simplify 3/(x+1) - 1/(x+1).
    [ ] 2/x
    [CORRECT] 2/(x + 1)
    [ ] 3/x
    [ ] (x + 2)/(x + 1)
- Q: Simplify $\frac{1}{x} + \frac{2}{x}$.
    [ ] $\frac{2}{x^2}$
    [ ] $\frac{3}{2x}$
    [ ] $\frac{x + 2}{x}$
    [CORRECT] $\frac{3}{x}$
- Q: What is the first essential step when adding two rational expressions that have unlike denominators?
    [ ] Add the numerators and the denominators separately
    [CORRECT] Rewrite both fractions over a common denominator
    [ ] Invert each of the two fractions and then multiply
    [ ] Factor only the numerator of each of the fractions

### Solving rational equations and modeling

- Q: Why is multiplying both sides by the least common denominator a useful strategy for solving a rational equation?
    [CORRECT] It clears the denominators, and equivalent solutions are kept if restrictions are checked
    [ ] It guarantees that no extraneous solutions can ever be introduced into the work
    [ ] It removes the variable from the equation completely and all at one step
    [ ] It converts every rational equation directly into a single linear equation to solve
- Q: Solve 1/x = 3.
    [ ] x = -3
    [ ] x = 0
    [ ] x = 3
    [CORRECT] x = 1/3
- Q: A car travels 120 miles at a constant speed r and the trip takes 3 hours. Which equation models this situation?
    [ ] 120 + r = 3
    [CORRECT] 120/r = 3
    [ ] 120 * r = 3
    [ ] r/120 = 3
- Q: Solve 1/(x - 2) = 1/3.
    [ ] x = 6
    [ ] x = 1
    [CORRECT] x = 5
    [ ] x = -1
- Q: After solving a rational equation, what must always be checked before accepting a candidate solution?
    [ ] Whether both sides of it have been fully simplified
    [CORRECT] Whether it makes any original denominator equal to zero
    [ ] Whether the value it produces happens to be positive
    [ ] Whether the value it produces happens to be an integer
