**The big idea**: **Evaluating functions and function notation** taught you to read $f(x)$ as a machine — one input in, one output out. **Domain and range** taught you that the machine has a door: a set of inputs it agrees to accept. **Absolute value equations** taught you that $|x-2| = 5$ splits into two cases. And **Introduction to inverse functions** taught you that some machines can be run backwards. This lesson stops treating those as four separate tricks and starts *building new functions out of old ones*. Three constructions do all the work. A **piecewise** definition glues several rules together, each owning its own slice of the domain — and the absolute value function is the smallest interesting example of one. **Composition** wires two machines in series, so the output of the first becomes the input of the second, which makes the inner function's outputs collide with the outer function's domain. And composition is precisely what upgrades "$g$ undoes $f$" from a feeling into a test you can run: two compositions, both of which must hand back $x$ untouched.

**Key concepts**

- **Absolute value and piecewise functions start with one definition: $|x|$ is the distance from $x$ to $0$, always reported as a nonnegative number.** The mechanism is "strip the sign, keep the size". $|-7| = 7$ because $-7$ sits seven units from zero; $|7| = 7$ for the same reason; $|0| = 0$. Without the distance reading you fall for three near-misses: $|x|$ is not $x^2$ (that makes $|-7| = 49$), not the negation $-x$ (that makes $|7| = -7$, and distances are never negative), and not the sign of $x$, which returns only $+1$ or $-1$ and forgets the size.
- **Absolute value is a two-rule piecewise function, and writing it that way removes all the mystery.** Define $f(x) = x$ for $x \ge 0$ and $f(x) = -x$ for $x < 0$. To evaluate $f(-3)$, first *choose the rule*: $-3 < 0$, so the second line applies and $f(-3) = -(-3) = 3$. The minus sign does not mean "make the answer negative"; it means "negate whatever came in", and negating a negative gives a positive. Feed the same machine $+3$ and the first line applies: $f(3) = 3$. Both inputs return 3 — that is the V-shaped graph.
- **A piecewise function's defining advantage is that it applies different rules on different parts of the domain.** That is the whole idea, and it is worth stating negatively too: it does not remove domain restrictions, it does not force one single rule to describe everything, and it is not limited to linear pieces. A shipping charge of \$0 under \$50, \$5 from \$50 up to \$200, and \$12 above that is three rules on three intervals: an order of \$200 costs \$5, an order of \$201 costs \$12. Each input must land in exactly one piece — overlapping intervals would return two outputs for one input and stop being a function. Watch which side owns the boundary: $x \ge 0$ hands $0$ to the first rule, $x > 0$ hands it to the second.
- **An absolute value equation is the two-case split you already know, read off that same V.** $|x - 2| = 5$ asks which inputs sit five units from 2, so $x - 2 = 5$ or $x - 2 = -5$, giving $x = 7$ or $x = -3$. Check both, always: $|7-2| = 5$ and $|-3-2| = |-5| = 5$. Quoting only $x = 7$ throws away half the solution set, and $x = 3$ or $x = -7$ is what you get by splitting the 2 instead of the 5. The count follows the geometry: a positive right-hand side gives two solutions, $|x-2| = 0$ gives one, and $|x-2| = -5$ gives none, because a distance cannot be negative.
- **Composite functions run two machines in series, and the notation reads right to left.** $(f \circ g)(x)$ — written in the question bank as `(f o g)(x)` — means $f(g(x))$: apply $g$ first, then $f$ to the result. It is neither $f(x) + g(x)$ nor $f(x) \cdot g(x)$; nothing is added or multiplied. With $f(x) = x - 4$ and $g(x) = 3x$, evaluate $(g \circ f)(2)$ inside out: $f(2) = -2$, then $g(-2) = -6$.
- **Order matters, because composition is not commutative.** Reverse the same pair: $(f \circ g)(2) = f(6) = 2$. Same two functions, same input, answers $-6$ and $2$. One habit carries this topic: *identify the inner function before you compute anything*.
- **Composing symbolically is substitution: replace every $x$ in the outer rule with the entire inner expression.** With $f(x) = 2x + 1$ and $g(x) = x^2$, the composite $(f \circ g)(x) = f(x^2) = 2(x^2) + 1 = 2x^2 + 1$. Keep the brackets while you substitute; they stop you writing $2x^2$ as $(2x)^2$. The other order is genuinely different: $(g \circ f)(x) = (2x+1)^2$.
- **The domain of a composite is a two-part gate, and the second part is the one people miss.** For $(f \circ g)(x)$ to be defined at $x$, first $x$ must be in the domain of $g$, and second **the output $g(x)$ must lie in the domain of $f$** — because $f$ has to be able to accept $g(x)$ as its input. Take $f(x) = \sqrt{x}$ and $g(x) = x - 1$. Every real number is a legal input to $g$, so the whole restriction comes from $f$, whose domain is $[0, \infty)$: we need $x - 1 \ge 0$, so $x \ge 1$. At $x = 1$, $\sqrt{0}$ is fine; at $x = 0.5$, $\sqrt{-0.5}$ is not real. Note that $x \ge 0$ is the domain of $f$ alone — the requirement travels *through* $g$ and comes out shifted.
- **Verifying inverse functions is composition used as a test: $(f \circ g)(x) = x$ and $(g \circ f)(x) = x$, on suitable domains.** Run the machines in both orders and demand that each round trip hand back exactly what you put in. With $f(x) = 3x$ and $g(x) = x/3$: $g(f(7)) = g(21) = 7$, and symbolically $f(g(x)) = 3 \cdot \frac{x}{3} = x$. With $f(x) = x + 5$ and $g(x) = x - 5$: $f(g(x)) = (x - 5) + 5 = x$. Note what the test is *not*: not $f(x) = g(x)$ for every $x$ (that says they are the same function, not opposite ones), not "the same slope", not "the same graph" — an inverse's graph is the original reflected across $y = x$.
- **Both directions are required, and one example shows why.** Let $f(x) = x^2$ and $g(x) = \sqrt{x}$. One order gives $f(g(x)) = (\sqrt{x})^2 = x$ for every $x \ge 0$, which looks like a pass. The other gives $g(f(x)) = \sqrt{x^2} = |x|$, and at $x = -4$ that returns $4$, not $-4$. Checking one composition alone would have certified a false inverse.
- **To find an inverse, swap the roles of input and output and re-solve; then verify.** For $f(x) = 2x - 1$, write $y = 2x - 1$, exchange the letters to get $x = 2y - 1$, and solve: $y = \frac{x+1}{2}$. Verify rather than trust: $f\!\left(\frac{x+1}{2}\right) = (x+1) - 1 = x$. The popular wrong answer $\frac{x-1}{2}$ fails in one line — $2 \cdot \frac{x-1}{2} - 1 = x - 2$ — because it undoes the steps in the wrong order. Since $f$ multiplies by 2 and *then* subtracts 1, the inverse adds 1 and *then* divides by 2.
- **Domain restrictions matter because a function must be one-to-one there to be invertible.** One-to-one means every output comes from exactly one input — what the horizontal line test checks on a graph. $f(x) = x^2$ over all real numbers sends both $3$ and $-3$ to $9$, so a would-be inverse would have to send $9$ back to two places, which a function may not do. Restrict the domain to $x \ge 0$ and the map becomes one-to-one, at which point $\sqrt{x}$ genuinely is the inverse. That restriction is exactly the "suitable domains" clause in the verification test.

**Rules to remember**

- $|x|$ is the distance from $x$ to $0$, so it is never negative: $|-7| = 7$.
- The absolute value function is the piecewise rule $x$ for $x \ge 0$ and $-x$ for $x < 0$; $f(-3) = 3$.
- Piecewise means different rules on different parts of the domain, each input landing in exactly one piece.
- $|X| = c$ with $c > 0$ splits into $X = c$ and $X = -c$: two solutions, and both must be checked.
- $(f \circ g)(x) = f(g(x))$ — inner function first. It is not addition, not multiplication, and not commutative.
- To compose symbolically, substitute the whole inner expression for every $x$ in the outer rule, brackets included.
- Domain of $(f \circ g)$: $x$ must be legal for $g$, **and** $g(x)$ must be legal for $f$.
- $f$ and $g$ are inverses exactly when $(f \circ g)(x) = x$ and $(g \circ f)(x) = x$ on suitable domains.
- Find an inverse by swapping $x$ and $y$ and solving; undo the operations in reverse order.
- Only a one-to-one function is invertible, which is why domains get restricted.

**Common pitfalls**

- Treating $|x|$ as $x^2$ or as $-x$. Squaring changes the size; negating breaks on positive inputs.
- Reading the $-x$ branch as "the answer is negative". At $x = -3$ it produces $+3$.
- Splitting $|x-2| = 5$ around the wrong number, landing on $x = 3$ or $x = -7$, or keeping only one branch.
- Composing in the written order rather than the applied order: $(f \circ g)$ applies $g$ first.
- Assuming $(f \circ g) = (g \circ f)$. With $f(x) = x-4$ and $g(x) = 3x$ at $x = 2$ they differ by 8.
- Dropping brackets during substitution, turning $2(x^2) + 1$ into $(2x)^2 + 1$.
- Giving the domain of $f$ as the domain of $f \circ g$: for $\sqrt{x}$ over $x - 1$ it is $x \ge 1$, not $x \ge 0$.
- Verifying an inverse in one direction only, or checking $f(x) = g(x)$ instead of $f(g(x)) = x$.
- Inverting $2x - 1$ as $\frac{x-1}{2}$ — undoing the steps in the order performed rather than in reverse.

**How to approach the questions**

1. For any absolute value item, say the definition first: distance from zero, never negative. Three of the four options usually die immediately.
2. For a piecewise evaluation, work in two visible steps — pick the rule the input qualifies for, *then* substitute. Most wrong answers come from substituting into the other line.
3. For a conceptual piecewise question, the answer names different rules on different parts of the domain. Options about "one single rule", "only linear", or "removing restrictions" are distractors.
4. For composition, mark the inner function before touching numbers and work inside out. A number means evaluate; two rules mean substitute and simplify.
5. For a composite domain, ask what the inner function accepts and then what the outer function accepts from it, and translate the second into an inequality in $x$.
6. For an inverse, do not eyeball it: compose. Substitute the candidate into $f$, simplify, and require a bare $x$. If a question asks *why* both directions or *why* domains matter, the answers are "each must undo the other" and "invertibility requires one-to-one".
