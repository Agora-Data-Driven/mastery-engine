### Absolute value and piecewise functions

- Q: A piecewise function is defined by f(x) = x for x >= 0 and f(x) = -x for x < 0. What is f(-3)?
    [ ] 0
    [ ] 9
    [CORRECT] 3
    [ ] -3
- Q: Solve the equation |x - 2| = 5 for x.
    [ ] x = 3 or x = -7
    [ ] x = 7 only
    [CORRECT] x = 7 or x = -3
    [ ] x = -3 only
- Q: For a real number $x$, what does the absolute value $|x|$ represent?
    [CORRECT] The distance of $x$ from $0$, always reported as nonnegative
    [ ] The plain arithmetic square of the number $x$, namely $x^2$
    [ ] The exact opposite, or negation, of the original number $x$
    [ ] The sign of the number $x$, taking either the value $+1$ or $-1$
- Q: What is the defining advantage of a piecewise function?
    [ ] It can only ever be used to define and graph linear functions
    [CORRECT] It applies different rules on different parts of the domain
    [ ] It completely removes every existing restriction on the domain
    [ ] It lets one single rule fully describe an entire function
- Q: Evaluate the absolute value |-7|.
    [ ] -7
    [CORRECT] 7
    [ ] 49
    [ ] 0

### Composite functions

- Q: What does the composite function (f o g)(x) mean?
    [ ] Add the values f(x) and g(x)
    [ ] Multiply the values f(x) and g(x)
    [CORRECT] Apply g first, then apply f to the result
    [ ] Apply f first, then apply g to the result
- Q: If f(x) = x - 4 and g(x) = 3x, find (g o f)(2).
    [ ] -2
    [ ] 6
    [CORRECT] -6
    [ ] 2
- Q: If f(x) = sqrt(x) and g(x) = x - 1, what is the domain of (f o g)(x)?
    [ ] x >= 0
    [ ] x <= 1
    [CORRECT] x >= 1
    [ ] All real numbers
- Q: For the composite (f o g)(x) to be defined at a point x, why must the output g(x) lie in the domain of f?
    [ ] Because g must be an invertible function
    [ ] Because composition requires f and g to be equal
    [CORRECT] Because f must be able to accept g(x) as its input
    [ ] Because the domains of f and g never matter here
- Q: If $f(x) = 2x + 1$ and $g(x) = x^2$, find $(f \circ g)(x)$.
    [ ] $x^2 + 1$
    [CORRECT] $2x^2 + 1$
    [ ] $2x + 1$
    [ ] $(2x + 1)^2$

### Verifying inverse functions

- Q: Which condition confirms that two functions f and g are inverses of each other?
    [CORRECT] (f o g)(x) = x and (g o f)(x) = x on suitable domains
    [ ] The equation f(x) = g(x) holds for every value of x
    [ ] The functions f and g share identical slopes everywhere
    [ ] The functions f and g share exactly the same graph
- Q: Let f(x) = 3x and g(x) = x/3. What is g(f(7))?
    [ ] 49/3
    [CORRECT] 7
    [ ] 7/3
    [ ] 21
- Q: Why do domain restrictions matter when checking whether a function has an inverse?
    [ ] Because only linear functions are ever able to have inverses
    [ ] Because only quadratic functions can ever possibly have inverses
    [ ] Because an inverse completely ignores all the function's outputs
    [CORRECT] Because the function must be one-to-one there to be invertible
- Q: Let f(x) = x + 5 and g(x) = x - 5. What is f(g(x))?
    [ ] 5
    [CORRECT] x
    [ ] x - 10
    [ ] x + 10
- Q: Which function is the inverse of f(x) = 2x - 1?
    [CORRECT] (x + 1)/2
    [ ] (x - 1)/2
    [ ] 1 - 2x
    [ ] 2x + 1
