1. From Equation To Graph

Absolute value equations already had you split |x - 2| = 5 into two cases. Here is the same split as a picture: |x - a| is a function with a V-shaped graph, and solving is asking where that V reaches the height c. Drag both and watch the two cases appear, merge, and vanish. Like asking who lives exactly five minutes from the station — two houses, one on each side.

already taught — an equation
|x - 2| = 5 x - 2 = 5 -> x = 7 x - 2 = -5 -> x = -3
this lesson — a function
f(x) = |x - 2| f(x) = x - 2 for x >= 2 f(x) = 2 - x for x < 2

Read the V as a distance meter: its height above the axis is how far x is from a, and a distance is never negative — which is why the whole graph sits on or above the axis and why a negative c has nothing to intersect. Every claim about |x| in this lesson is that one sentence in disguise: |-7| = 7 because -7 sits seven units from zero, not because anything was squared or negated.

2. Pick The Piece

A piecewise function applies different rules on different parts of the domain, so evaluating it is always two steps: choose the rule the input qualifies for, then substitute. Slide the input and watch the active rule light up. Like a postage table: you find your weight band first, and only then read a price.

Two structural rules keep a piecewise definition legal, and both are visible above. The conditions must not overlap — an input matching two rules would have two outputs, and a function is allowed only one — and between them they should cover every input you intend to accept, or the function is simply undefined there. Boundaries are where this is decided: x >= 0 gives 0 to the first rule, x > 0 gives it to the second.

3. Inner Then Outer

(f o g)(x) means f(g(x)): g runs first, f runs on what comes out. Nothing is added and nothing is multiplied. Feed a number in, swap the order, and watch the answer change. Like a factory line: paint then dry is not the same product as dry then paint.

The symbolic version is the same move done with a letter instead of a number: replace every x in the outer rule with the whole inner expression, brackets and all. With f(x) = 2x + 1 and g(x) = x^2 that gives 2(x^2) + 1 = 2x^2 + 1 — and dropping the brackets to write (2x)^2 + 1 is a different function entirely, which is exactly what one of the distractors is.

4. Domain Of The Chain

A composite is defined at x only if two gates open: x must be legal for the inner function, and its output must be legal for the outer one. Slide x along the line and watch the second gate do most of the work. Like a connecting flight: your first leg has to land somewhere the second leg actually departs from.

Notice which answer the machinery does not give. For sqrt(x) composed with x - 1 the domain is x >= 1, not x >= 0 — x >= 0 is the domain of sqrt on its own, and the requirement has to be dragged back through the inner function before it means anything about x. That translation step is the whole skill here, and it is why the condition is stated as g(x) must lie in the domain of f rather than as a rule about x.

5. Round Trip Check

Two functions are inverses when both round trips land back where they started: f(g(x)) = x and g(f(x)) = x, on suitable domains. Pick a candidate, slide the input, and see which candidates survive both trips. Like a key and a lock: turning one way then the other has to leave the door exactly as you found it.

The one-to-one requirement is what the "suitable domains" clause is protecting. A function is invertible on a set only if every output there comes from exactly one input — so x^2 over all real numbers cannot be inverted, because 3 and -3 both land on 9 and the return trip would have to split in two. Restrict the domain to x >= 0 and sqrt genuinely becomes its inverse. Restricting the domain is not a technicality; it is what makes the inverse exist.
