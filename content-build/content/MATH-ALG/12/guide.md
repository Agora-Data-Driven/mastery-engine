**The big idea**: **Vertex form and features of quadratic graphs** let you read $y = a(x-h)^2 + k$ and place the parabola at $(h, k)$ before plotting a single point, and **Standard and expanded equations of a circle** used the very same $(x-h)$ and $(y-k)$ to slide a circle anywhere on the plane. Those were never two facts about two curves. They were one set of rules about *any* graph, written twice with the starting curve — $x^2$, or the unit circle — hard-coded into them. This lesson removes the starting curve. Call it $f$, keep the notation from **Evaluating functions and function notation**, and every move splits cleanly in two: anything written **outside** $f$ acts on the output and does exactly what it says, while anything written **inside** $f$ acts on the input and runs backwards. **Composite functions** already explained why the inside is backwards — $f(x-2)$ is $f$ composed with $s(x) = x - 2$, so $s$ runs first, on the input. Three ideas carry the whole lesson: shifts and reflections relocate a graph without changing its shape, a multiplier outside $f$ rescales every output, and a graph that a reflection leaves *unchanged* earns a name.

**Key concepts**

- **Shifting and reflecting functions is one principle applied four ways: outside changes the height, inside changes the input.** Mechanism: a graph is the set of points $(x, f(x))$, so a symbol outside $f$ can only edit the second coordinate and one inside can only edit the first. $g(x) = f(x) + 3$ lifts every height, sending $(2,4)$ to $(2,7)$ on $f(x) = x^2$; $g(x) = f(x-2)$ leaves heights alone and asks $f$ a different question. Why it matters: the two families never mix — no amount of shifting upward will ever slide a graph sideways — so locating the symbol relative to the parentheses answers most transformation questions before any algebra starts.
- **A vertical shift $y = f(x) + k$ moves the graph up by $k$, and down when $k$ is negative.** Mechanism: the map on points is $(x, y) \mapsto (x, y + k)$ — the input is untouched, so the shape is untouched. Numbers on $f(x) = x^2$: the outputs $f(0) = 0$, $f(1) = 1$, $f(2) = 4$ become $3$, $4$, $7$ under $y = f(x) + 3$, every one raised by exactly 3. This is the $+k$ of vertex form, now stated without the parabola.
- **A horizontal shift $y = f(x-h)$ moves the graph RIGHT by $h$, and the minus sign is not a quirk to memorise.** Mechanism: let $g(x) = f(x-h)$ and ask where $g$ does what $f$ did at input $t$. Solve $x - h = t$, giving $x = t + h$ — every feature relocates $h$ units to the right. Numbers: $f(x) = x^2$ puts its vertex where the input is $0$; for $y = (x-2)^2$ the input is $0$ when $x = 2$, so the vertex travels from $(0,0)$ to $(2,0)$ — shifted right by 2, despite the visible minus.
- **Two reflections, one per side of the parentheses: $y = -f(x)$ flips across the $x$-axis, $y = f(-x)$ flips across the $y$-axis.** Mechanism: $-f(x)$ negates the output, $(x, y) \mapsto (x, -y)$, tipping the graph over the horizontal axis; $f(-x)$ negates the input, $(x, y) \mapsto (-x, y)$, swapping left for right. Numbers on $f(x) = x^2$: $-f(3) = -9$, so $(3, 9)$ becomes $(3, -9)$ and the expression is $-x^2$, an upside-down parabola. Meanwhile $f(-3) = (-3)^2 = 9$, so $f(-x) = (-x)^2 = x^2$ and nothing moved. Keep those apart — $-x^2$ and $(-x)^2$ are different functions, and only the first is $-f(x)$.
- **Scaling functions vertically: $g(x) = a\,f(x)$ multiplies every output by $a$.** Mechanism: $(x, y) \mapsto (x, a y)$, a purely vertical move whose size depends on how far the point already sat from the $x$-axis, so a tall part of the curve travels further than a short one and the shape genuinely changes. With $a > 1$ it is a vertical stretch: $y = 3f(x)$ triples every height, sending $2$ to $6$ and $-1$ to $-3$. With $0 < a < 1$ it compresses toward the axis, so $y = \tfrac{1}{2} f(x)$ halves each output value. The rule is pointwise, so it applies to a single known value with no graph in sight: given $f(2) = -4$, $3f(2) = 3 \times (-4) = -12$. The sign survives; only the size changes.
- **A vertical scaling fixes every $x$-intercept, and that is how you tell it from a shift.** Mechanism: $a \times 0 = 0$ for every $a$, so wherever $f$ crossed zero, $af$ still crosses zero. On $f(x) = x + 1$ that crossing is at $x = -1$, and $4f$, $\tfrac{1}{2}f$ and $-2f$ all still cross there, while the shifted $f(x) + 3 = x + 4$ crosses at $x = -4$ instead.
- **The multiplier hits the entire rule, because $a f(x)$ means "evaluate $f$, then multiply".** Mechanism: substitute first, scale second. If $f(x) = x + 1$ then $g(x) = 4f(x) = 4(x + 1) = 4x + 4$ — the distributive law from the first lesson of this course, not a new rule. Check it numerically: $f(3) = 4$, so $4f(3) = 16$, and $4x + 4$ at $x = 3$ is indeed $16$, while the tempting $4x + 1$ gives $13$. Nor is $4f(x)$ the same as $f(4x) = 4x + 1$, which multiplies the *input* before $f$ ever runs.
- **A negative multiplier is a reflection and a stretch: $g(x) = -2f(x)$ reflects the outputs over the $x$-axis, then stretches them by 2.** Mechanism: $-2f(x) = 2\left(-f(x)\right)$, so it factors into the $x$-axis reflection above followed by a stretch of size $|a| = 2$; multiplication commutes, so the other order lands on the same points. Numbers: $f(2) = -4$ gives $-2f(2) = 8$ — not a downward shift of 2, which would give $-6$, and not "inputs doubled first", which would be $f(2x)$. The size $|a|$ is the stretch, the sign of $a$ is the flip.
- **Symmetry (Even and Odd functions) asks which graphs a reflection leaves alone.** A function is **even** when $f(-x) = f(x)$ for every $x$ in its domain: the $y$-axis reflection returns the original graph, so the graph is symmetric about the $y$-axis. It is **odd** when $f(-x) = -f(x)$ for every $x$: the $y$-axis reflection is exactly undone by an $x$-axis reflection, and the two together are a half-turn about the origin, so the graph is symmetric about the origin. Numbers: $f(x) = x^2$ gives $f(-3) = 9 = f(3)$, even. $f(x) = x^3$ gives $f(-2) = -8 = -f(2)$, odd.
- **For a power, the parity of the function is the parity of the exponent, because $(-x)^n = (-1)^n x^n$.** Mechanism: $(-1)^n$ is $+1$ for even $n$ and $-1$ for odd $n$, which is the two definitions verbatim. So $x^2$ and $x^4$ are even, $x$, $x^3$ and $x^5$ are odd, and a constant function is even because $f(-x) = c = f(x)$. Sums keep a parity only when their terms agree on it: $x^5 + x$ is odd (at $x = 2$ it is $34$, and $f(-2) = -34$) and $x^2 + 1$ is even ($f(-3) = 10 = f(3)$). In a list of $x^4$, $x^2 + 1$ and $x^3$, then, only $x^3$ is odd.
- **Most functions are neither, and "for every $x$" is what decides it.** One counterexample is fatal and one lucky point proves nothing. Take $f(x) = x^2 + x$: at $x = 1$, $f(1) = 2$ and $f(-1) = 0$, so $0 \neq 2$ rules out even and $0 \neq -2$ rules out odd. Notice $f(0) = 0$ there — passing through the origin does not make a function odd.
- **Parity is a machine for producing values you were never given.** If $f$ is odd and $f(3) = -2$, then $f(-3) = -f(3) = -(-2) = 2$; had $f$ been even, $f(-3)$ would be $-2$. Substituting $x = 0$ into the odd condition proves a small theorem: $f(0) = -f(0)$, so an odd function defined at $0$ has $f(0) = 0$. Parity says nothing beyond that — an even function may have any number of $x$-intercepts, and neither condition forces a function to increase anywhere.

**Rules to remember**

- Outside the parentheses acts on the output and does what it says; inside acts on the input and runs backwards.
- $f(x) + k$: up for $k > 0$, down for $k < 0$. $f(x - h)$: right for $h > 0$, left for $h < 0$.
- $-f(x)$ reflects across the $x$-axis; $f(-x)$ reflects across the $y$-axis; $-x^2$ and $(-x)^2$ are not the same.
- $a f(x)$ multiplies every output by $a$: a stretch when $|a| > 1$, a compression when $|a| < 1$.
- A negative $a$ means reflect over the $x$-axis, then stretch by $|a|$.
- Scaling preserves $x$-intercepts; shifting moves them.
- $a f(x)$ scales the whole rule: with $f(x) = x + 1$, $4f(x) = 4x + 4$.
- Even is $f(-x) = f(x)$ with $y$-axis symmetry; odd is $f(-x) = -f(x)$ with origin symmetry; both must hold for every $x$.

**Common pitfalls**

- Reading $f(x - 2)$ as a shift to the left. Solve $x - 2 = 0$ rather than guessing from the sign.
- Confusing $-f(x)$ with $f(-x)$. One tips the graph over, the other swaps its left and right sides.
- Writing $-f(x)$ as $(-x)^2$ when $f(x) = x^2$. That expression simplifies to $x^2$ and is the *other* reflection.
- Scaling only one term: $4f(x)$ with $f(x) = x + 1$ is $4x + 4$, never $4x + 1$ and never $x + 4$.
- Calling $y = 3f(x)$ an upward shift by 3, a reflection, or a horizontal stretch. It is a vertical stretch by a factor of 3.
- Reading $-2f(x)$ as a downward shift of 2, or as doubling the inputs before $f$ runs.
- Dropping the sign of a sampled value: with $f(2) = -4$, $3f(2)$ is $-12$, not $12$ and not $-6$.
- Declaring a function odd because its graph passes through $(0,0)$, or from a single agreeable point.
- Assuming every function is even or odd. Most, like $x^2 + x$, are neither, and that is a legitimate answer.

**How to approach the questions**

1. Locate the symbol relative to $f$'s parentheses before anything else. Outside means output; inside means input, running backwards.
2. For a shift, set the inside expression equal to $0$ and solve. The solution is where the old $x = 0$ feature now lives.
3. When a rule such as $f(x) = x + 1$ is supplied, substitute and simplify before comparing with the options: $4(x+1)$ and $4x + 4$ are the same function.
4. When only a value such as $f(2) = -4$ is supplied, do the arithmetic with the sign attached. The graph is not required.
5. For a "describe the effect" option, check that it names the correct *side*: wording about inputs being doubled describes something written inside $f$, so it cannot describe $-2f(x)$.
6. For even or odd, substitute $-x$, simplify, then compare against both $f(x)$ and $-f(x)$ at a value where those two differ. Matching neither is the common outcome.
