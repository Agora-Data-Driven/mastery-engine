### Shifting and reflecting functions

- Q: Starting from y = f(x), what transformation does the graph of y = f(-x) represent?
    [ ] A shift to the left
    [ ] A shift downward
    [CORRECT] A reflection across the y-axis
    [ ] A reflection across the x-axis
- Q: Starting from y = f(x), what transformation does the graph of y = f(x) + 3 represent?
    [CORRECT] A shift upward by 3 units
    [ ] A shift to the left by 3 units
    [ ] A shift to the right by 3 units
    [ ] A reflection across the x-axis
- Q: If $f(x) = x^2$, how is the graph of $y = (x - 2)^2$ positioned relative to $y = x^2$?
    [CORRECT] Shifted to the right by 2
    [ ] Shifted to the left by 2
    [ ] Reflected across the y-axis
    [ ] Shifted upward by 2
- Q: If $f(x) = x^2$, which expression equals $y = -f(x)$?
    [CORRECT] $-x^2$
    [ ] $(-x)^2$
    [ ] $x^2 - 1$
    [ ] $x^2$

### Scaling functions vertically

- Q: If f(x) = x + 1, what is the rule for g(x) = 4f(x)?
    [ ] g(x) = 4x + 1

    [CORRECT] g(x) = 4x + 4
    [ ] g(x) = x + 5

### Symmetry (Even and Odd functions)

- Q: A function f is called odd when which condition holds for every x in its domain?
    [ ] f has no x-intercepts at all
    [CORRECT] f(-x) = -f(x) for all x
    [ ] f(-x) = f(x) for all x
    [ ] f is increasing on its domain
- Q: Which of the following functions is odd (symmetric about the origin)?
    [ ] $f(x) =$
    [ ] $x$
    [ ] $f(x) = x^4$
    [ ] $f(x) = x^2 + 1$
    [CORRECT] $f(x) = x^3$
- Q: Which of the following functions is even (symmetric about the y-axis)?
    [ ] $f(x) = x$
    [ ] $f(x) = x^5 + x$
    [ ] $f(x) = x^3$
    [CORRECT] $f(x) = x^2$
- Q: A function f is called even when which condition holds for every x in its domain?
    [ ] f(-x) = -f(x) for all x
    [ ] Its graph passes through (0,0)
    [ ] f(x) > 0 for all x
    [CORRECT] f(-x) = f(x) for all x
- Q: If f is an odd function and f(3) = -2, what is the value of f(-3)?
    [ ] f(-3) = 3
    [ ] f(-3) = -3
    [ ] f(-3) = -2
    [CORRECT] f(-3) = 2
