1. Vertex Form Again

You have been moving graphs for four lessons already — vertex form puts a parabola at (h, k), and the circle equation puts a centre there with the same two letters. Swap the parabola for any curve f and the rules survive untouched. Drag h and k, then change f. Like sliding a sofa across a room: it does not change shape, only where it sits.

already yours
y = a(x - h)^2 + k vertex sits at (h, k) (x - h)^2 + (y - k)^2 = r^2 centre sits at (h, k)
this lesson, general
y = f(x - h) + k for ANY starting curve f h is INSIDE -> moves sideways k is OUTSIDE -> moves up/down

Nothing on this panel is specific to a parabola. That is the whole point of writing the rule with a nameless f: one statement replaces a separate memorised fact for every curve you will ever meet — circles, absolute values, cubes, and the square roots and exponentials still to come.

2. Inside Or Outside

One shift written outside f, the same number written inside. Drag c and watch them disagree: outside obeys the sign, inside does the opposite. The table shows why it has to. Like a clock set five minutes fast: you see the hands move forward, so you arrive five minutes early.

The reliable move is never to remember a direction. Set the inside expression equal to zero and solve. Wherever that lands is where the old x = 0 feature now sits, and the same one-line trick will still work in a year when the inside reads 2x + 5 instead of x - 2.

3. Two Mirrors

There are exactly two mirrors, one per side of the parentheses. Switch each on and off, change the starting curve, and watch for the case where a mirror changes nothing at all — that case has a name, and it is visual 5. Like a photograph: one flip turns it upside down, the other swaps left and right, and doing both is a half-turn.

Write the two results out as expressions and the difference stops being visual. With f(x) = x^2 the outside mirror gives -x^2 and the inside mirror gives (-x)^2 = x^2. Those are different functions and only the first one is -f(x) — the minus sign lands on the answer, not on the x.

4. Stretch The Outputs

A multiplier written outside f multiplies every output by the same number. Drag a and watch three things move together: the graph, the algebra of the rule, and a single sampled value. Watch what never moves — the x-intercept. Like turning up a volume dial: the loud parts gain far more than the quiet ones, and silence stays silent.

Two fingerprints separate this from a shift, and both are visible above. A scaling pins every x-intercept in place, because a times 0 is 0 whatever a is; a shift drags those crossings along with everything else. And a scaling changes the shape, while a shift never does.

5. Fold Or Spin

Now run visual 3 backwards: instead of asking what a mirror does to a graph, ask which graphs a mirror leaves alone. Pick a function, fold it across the y-axis, spin it about the origin, and read the verdict. Like a butterfly versus a playing card: one matches when folded, the other matches when turned upside down.

Both conditions are stated for every x in the domain, and that phrase is the whole difficulty. One value where the test fails settles the matter for good, while one value where it passes settles nothing — x^2 + x agrees with oddness at x = 0 and fails everywhere else. Most functions are neither, and "neither" is a real answer, not a sign you have gone wrong.
