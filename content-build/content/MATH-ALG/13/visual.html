1. From Count To Fraction

Exponent properties (integer exponents) built the exponent as a count of repeated factors, so only whole numbers made sense up there. Insist that the nesting rule keeps working and the count is forced to become a fraction — which is a root. Drag the numerator and the denominator and watch the new exponent land between the rungs you already have. Like a staircase you have always walked one step at a time, and now you can stand halfway up a step.

already taught
b^3 = b·b·b a count of factors b^0 = 1, b^-2 = 1/b^2 sqrt(50) = 5·sqrt(2) a separate rulebook
this lesson
(b^(1/n))^n = b^(n/n) = b so b^(1/n) IS the n-th root b^(m/n) = (n-th root of b)^m

Read the two orders in the working: rooting first keeps the arithmetic small, powering first blows it up and then shrinks it back. They always agree, so choose the small one — and notice that an even root of a negative base has no real value at all, which is why questions about b^(1/2) announce "for b ≥ 0" before they announce anything else.

2. Rules That Survive

Four statements look like exponent rules and only some are. Pick one, then move the numbers underneath it and watch the two sides agree or split apart — including the traps, where a false rule accidentally agrees at the numbers you happened to pick. Like an alibi that holds up for one evening: it can be broken by a single date, but never proved by one.

The judgment worth taking away is about evidence, not about exponents. A numeric test is a refutation machine: one disagreement kills a rule forever, but a thousand agreements prove nothing, because you only ever tested a thousand of infinitely many cases. Use the numbers to eliminate, then keep the survivor for the reason it is true — that nesting counts blocks of factors, so the counts multiply.

3. Square Then Check

Squaring both sides clears the radical — and quietly drags in the mirror-image curve underneath it. Every extraneous root you will ever meet is an honest crossing of that dashed phantom. Move the equation and watch which candidates land on the solid branch and which land on the ghost. Like casting a net for one fish and hauling in its reflection too.

Notice what the check is really testing: a candidate survives exactly when both sides come out with the same sign. A principal square root is never negative, so any candidate that forces the right-hand side below zero belongs to the mirror equation, not to yours. That is also why "why must you check?" is answered by naming the operation — squaring — and never by blaming the radical.

4. Match The Base

With the unknown up in the exponent there is nothing to isolate — so rewrite both sides on one base and read the exponents off. It works because the curve crosses a horizontal line exactly once. Pick a base, a shift and a target, and watch the rewrite succeed, degenerate, or run out of road. Like two prices quoted in different currencies: convert them first, and only then compare.

Two boundaries are worth carrying away. b = 1 is excluded because a flat line is not one-to-one: it meets its target everywhere or nowhere, never once. And a target that is not a power of the base cannot be reached by rewriting at all — the answer exists, it is simply trapped between two integers, which is the exact gap the next lesson fills.
