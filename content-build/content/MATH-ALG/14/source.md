    [ ] 1
    [CORRECT] 4

- Q: Evaluate $\log_2(8)$.
    [ ] 8
    [ ] 2
    [CORRECT] 3

- Q: Which expression represents the exponent to which 10 must be raised to get 100?
    [CORRECT] $\log_{10}(100)$

    [ ] What root of a number equals a value

### Relationship between exponentials and logs

- Q: Rewrite the logarithmic equation $\log_3(81) = 4$ in exponential form.
    [ ] $3^{81} = 4$
    [CORRECT] $3^4 = 81$
    [ ] $4^3 = 81$
    [ ] $81^3 = 4$
- Q: The equation $\log_b(a) = c$ is equivalent to which exponential statement?
    [CORRECT] $b^c = a$
    [ ] $c^b = a$
    [ ] $b^a = c$
    [ ] $a^c = b$
- Q: Rewrite the exponential equation $10^x = 1000$ in logarithmic form.
    [ ] $\log_x(1000) = 10$
    [ ] $\log_{1000}(10) = x$
    [CORRECT] $\log_{10}(1000) = x$
    [ ] $\log_{10}(x) = 1000$
- Q: Evaluate $\log_5(125)$.
    [ ] 4
    [CORRECT] 3
    [ ] 5
    [ ] 2
- Q: Which logarithmic equation is equivalent to the exponential equation $2^3 = 8$?
    [ ] $\log_2(3) = 8$
    [ ] $\log_8(2) = 3$
    [ ] $\log_3(2) = 8$
    [CORRECT] $\log_2(8) = 3$

### Properties of logarithms and Change of Base formula

- Q: For positive $x$ and $y$, which logarithm property is correct?
    [ ] $\log(x^2) = 2 + \log x$
    [CORRECT] $\log(xy) = \log x + \log y$
    [ ] $\log(x + y) = \log x + \log y$
    [ ] $\log(x/y) = \log x / \log y$
- Q: Condense $2\ln(x) - \ln(y)$ into a single logarithm.
    [ ] $\ln(x^2 - y)$
    [CORRECT] $\ln\left(\frac{x^2}{y}\right)$
    [ ] $\ln\left(\frac{x}{y^2}\right)$
    [ ] $\ln\left(\frac{2x}{y}\right)$
- Q: What is the main purpose of the change of base formula?
    [ ] It rewrites every logarithm so its value equals 1
    [CORRECT] It evaluates a log in any base using common or natural logs
    [ ] It converts a logarithm into a simple ratio of its inputs
    [ ] It removes the domain restrictions on a logarithm
- Q: Use the change of base formula to rewrite $\log_2(7)$ using natural logs.
    [ ] $\ln(7/2)$
    [CORRECT] $\frac{\ln(7)}{\ln(2)}$
    [ ] $\frac{\ln(2)}{\ln(7)}$
    [ ] $\ln(7) - \ln(2)$
- Q: Expand $\log_3(x^2 y)$ into a sum of logarithms.
    [ ] $2\log_3(xy)$
    [CORRECT] $2\log_3(x) + \log_3(y)$
    [ ] $\log_3(x) + \log_3(y^2)$
    [ ] $2\log_3(x) \times \log_3(y)$

### Exponential model word problems

- Q: An investment of 2000 loses 5% of its value each year. What is its value after 1 year?
    [ ] 2100
    [ ] 1950
    [ ] 1995
    [CORRECT] 1900
- Q: Which model represents a quantity with initial value $P$ growing at $8\%$ per year, after $t$ years?
    [ ] $P(0.08)^t$
    [CORRECT] $P(1.08)^t$
    [ ] $1.08 \times P \times t$
    [ ] $P + 0.08 \times t$
- Q: Which feature of a data table is the signature of exponential growth?
    [ ] A constant second difference per step
    [ ] A constant difference over equal intervals
    [ ] A negative value at the y-intercept
    [CORRECT] A constant ratio over equal intervals
- Q: A population starts at 500 and grows by 10% each year. Which equation models the population $P$ after $t$ years?
    [ ] $P = 500 \cdot t^{1.10}$
    [ ] $P = 500(0.10)^t$
    [ ] $P = 500 + 0.10 \cdot t$
    [CORRECT] $P = 500(1.10)^t$
- Q: A bacteria culture starts with 12 cells and doubles every hour. How many cells are present after 3 hours?
    [ ] 48
    [ ] 36
    [ ] 72
    [CORRECT] 96
