**The big idea**: **Chain Rule and Implicit differentiation** taught you to differentiate a composition. **Partial derivatives and the Gradient vector** extended that to many inputs at once, and **Directional derivatives** and **Higher-order derivatives and the Hessian matrix** described how a surface bends. **Square loss and log loss functions** gave you the scalar at the end, and **Gradients of cost functions (e.g., Mean Squared Error)**, **Introduction to Gradient Descent** and **Learning rate and convergence** gave you the loop that consumes the gradient. A neural network introduces no new calculus at all. It is a long composition of alternating affine maps and simple scalar nonlinearities, ending in one number. The genuinely new idea in this lesson is *bookkeeping*: how to apply the chain rule to a composition with millions of parameters without recomputing the same products millions of times. That bookkeeping is the backpropagation algorithm, and the data structure it runs on is the computational graph.

**Key concepts**

- **A layer is an affine map followed by a scalar nonlinearity.** Writing $g$ for the activation function, the standard formula is $a^{[l]} = g(W^{[l]} \cdot a^{[l-1]} + b^{[l]})$, and it is worth naming the pre-activation separately: $z^{[l]} = W^{[l]}a^{[l-1]} + b^{[l]}$, so $a^{[l]} = g(z^{[l]})$. The bracketed superscript indexes the **layer**, so $a^{[2]}$ is the output activation vector of the second layer — not $a_2$, which would be one component, and not $z_2$, which is a pre-activation. An **activation** is a neuron's output value *after* the activation function has been applied: how strongly that unit signals the units downstream. Worked: $a^{[0]} = (2,-1)^T$, $W^{[1]} = \begin{pmatrix}1&1\\-2&0\end{pmatrix}$, $b^{[1]} = (0,1)^T$ gives $z^{[1]} = (1,-3)^T$, and ReLU gives $a^{[1]} = (1,0)^T$ — the second unit is silent.

- **Without a nonlinearity, depth buys nothing, and you can prove it in one line.** Set $g$ to the identity. Then $a^{[2]} = W^{[2]}(W^{[1]}x + b^{[1]}) + b^{[2]} = (W^{[2]}W^{[1]})x + (W^{[2]}b^{[1]} + b^{[2]})$. Recall from linear algebra that a product of matrices is a matrix: the composition of two affine maps is an affine map, and by induction any depth of purely linear layers collapses to a single $W_{\text{eff}}, b_{\text{eff}}$. Numerically, $W^{[1]} = \begin{pmatrix}2&0\\0&3\end{pmatrix}$ and $W^{[2]} = (1\;\;1)$ give $W_{\text{eff}} = (2\;\;3)$. The whole network behaves as a single linear transformation — equivalent to one linear model, however many parameters it has. Non-linear activations between the hidden layers are exactly what let stacked layers model patterns a plain linear map cannot.

- **The activation functions you are examined on.** The logistic **sigmoid** $\sigma(z) = 1/(1+e^{-z})$ squashes any input to an output strictly between 0 and 1, never reaching either. **ReLU**, the rectified linear unit, is the rule $\max(0, z)$: it outputs $z$ when $z$ is positive and 0 otherwise. **Linear (identity)** leaves $z$ alone, for unbounded regression outputs. **Softmax** is the output-layer choice for multi-class problems where each input belongs to exactly one of several mutually exclusive classes: $\text{softmax}(z)_i = e^{z_i}/\sum_j e^{z_j}$, non-negative and summing to 1. Sigmoid is emphatically not the only function a network can use, and using others is what makes a network more powerful. Turning a binary output into a label is a *threshold*, not a change of function: an output activation of 0.84 predicts class 1 because $0.84 > 0.5$.

- **$\sigma'(z) = a(1-a)$, and that single line explains ReLU's dominance in hidden layers.** Differentiate $\sigma = (1+e^{-z})^{-1}$ by the chain rule: $\sigma' = e^{-z}(1+e^{-z})^{-2} = \sigma(1-\sigma) = a(1-a)$. Its maximum sits at $a = 0.5$, where it equals 0.25. Backpropagation multiplies one such factor per layer, so ten stacked sigmoids contribute at most $0.25^{10} \approx 9.5\times10^{-7}$ — the vanishing gradient, and the early layers effectively stop learning. ReLU's derivative is exactly 1 wherever $z > 0$, so the same product stays at 1 and the signal reaches the bottom of a deep image-classification network intact.

- **A computational graph names every intermediate variable.** Each node is deliberately something trivial — typically either a linear function or a sigmoid — so its **local** derivative is a one-liner, and each edge carries that local derivative. For one logistic neuron: $w \to z = wx+b \to \hat{y} = \sigma(z) \to L$. Then $\partial z/\partial w = x$, $\partial \hat{y}/\partial z = \hat{y}(1-\hat{y})$, and for log loss $\partial L/\partial \hat{y} = (\hat{y}-y)/(\hat{y}(1-\hat{y}))$. Because $w, z, \hat{y}, L$ form a chain of dependence, $\partial L/\partial w$ is the **product** of those three local derivatives, which collapses to $x(\hat{y}-y)$. With $x=2$, $w=0.5$, $b=0$, $y=1$: $z=1$, $\hat{y}=0.731$, so $\partial L/\partial w = 2(0.731-1) = -0.538$.

- **A node lying on two paths contributes a SUM of products.** If $x$ reaches $f$ through $x \to y_1 \to f$ and $x \to y_2 \to f$, the chain rule on graphs gives $\frac{\partial f}{\partial x} = \frac{\partial f}{\partial y_1}\frac{\partial y_1}{\partial x} + \frac{\partial f}{\partial y_2}\frac{\partial y_2}{\partial x}$. Check it on real numbers: $f = y_1y_2$ with $y_1 = x^2$ and $y_2 = 3x$ gives $(3x)(2x) + (x^2)(3) = 9x^2$, and differentiating $f = 3x^3$ directly gives $9x^2$ too. Multiply *along* a path, add *across* paths. In a network every hidden unit feeds many units in the next layer, so this branching case is the normal one, not an exception.

- **The backpropagation algorithm is the chain rule evaluated right-to-left with intermediates cached.** Suppose $L$ depends on $\hat{y}$, $\hat{y}$ on $z$, $z$ on $a_1$, $a_1$ on $z_1$, and $z_1$ on the weight $w_{11}$. Then $\partial L/\partial w_{11}$ is the product of those five derivatives along the dependency chain — never their sum. Each weight affects the loss only through a long series of intermediate variables, which is precisely why the chain rule is unavoidable here. Every weight in layer 1 shares the same suffix $\partial L/\partial a_1$, so intermediate derivatives are stored once they are computed because reusing them avoids recomputing identical quantities for every weight. One chain-rule computation is reused layer by layer, which is why the cost stays roughly proportional to a single forward pass however deep the network is. The algorithm's whole purpose is to produce the gradient of the loss with respect to every weight and bias so they can be updated; the updating itself is gradient descent's job.

- **The layer recursion, then the same thing as arithmetic.** Define $\delta^{[l]} = \partial L/\partial z^{[l]}$. Then $\partial L/\partial W^{[l]} = \delta^{[l]}(a^{[l-1]})^T$, $\partial L/\partial b^{[l]} = \delta^{[l]}$, and $\delta^{[l-1]} = \big((W^{[l]})^T\delta^{[l]}\big) \odot g'(z^{[l-1]})$. Concretely, with $x=1$, $w_1=0.5$, $b=0$: $z_1 = 0.5$, $a_1 = \text{ReLU}(0.5) = 0.5$; then $w_2 = 2$ gives $z_2 = 1.0$ and $\hat{y} = \sigma(1) = 0.7311$. Against target $y=0$ with square loss, $L = \tfrac12(\hat{y}-y)^2 = 0.2672$. Backward: $\partial L/\partial \hat{y} = 0.7311$; $\partial \hat{y}/\partial z_2 = 0.7311 \times 0.2689 = 0.1966$; $\delta_2 = 0.1437$; $\partial L/\partial w_2 = \delta_2 a_1 = 0.0719$; $\partial L/\partial a_1 = \delta_2 w_2 = 0.2875$; $\text{ReLU}'(0.5)=1$ so $\delta_1 = 0.2875$ and $\partial L/\partial w_1 = \delta_1 x = 0.2875$. The five-factor product gives the identical number: $0.7311 \times 0.1966 \times 2 \times 1 \times 1 = 0.2875$.

- **Why the field looks the way it does.** Neural networks were originally motivated by the goal of writing software that mimics how the biological brain learns, but deliberately copying the brain is not a viable path to powerful AI: our knowledge of how the brain actually works is still very limited. What changed recently is data. A large neural network keeps improving as the dataset grows, while logistic regression or linear regression plateaus — so the growth in available digital records, and the fact that large networks can take effective advantage of it, is the primary reason modern networks outperform earlier ones. Finally, running a downloaded, pre-trained network on new data with no further training is **inference**, not training: no backward pass runs at all.

**Rules to remember**

- $a^{[l]} = g(W^{[l]} \cdot a^{[l-1]} + b^{[l]})$. Bracketed superscripts index layers; $a^{[2]}$ is layer 2's output activation vector.
- Linear activations everywhere $\Rightarrow$ the whole network collapses to one equivalent single linear model.
- ReLU is $\max(0,z)$; sigmoid is strictly in $(0,1)$; softmax is for mutually exclusive multi-class outputs; identity is for unbounded regression.
- $\sigma'(z) = a(1-a) \le 0.25$; $\text{ReLU}'(z) = 1$ for $z>0$. Constant 1 is what mitigates vanishing gradients.
- Threshold a binary output activation at 0.5 to get a 0/1 prediction.
- Along one path: multiply the local derivatives. Across parallel paths: add the path products.
- $\partial L/\partial w$ over a chain of five variables is the product of five derivatives, not the sum.
- Cache intermediate derivatives — the reuse, not any change of formula, is what makes the algorithm scale with depth.
- The backpropagation algorithm math is just the chain rule with caching: it computes gradients, and gradient descent applies them. Two different jobs.

**Common pitfalls**

- **Thinking more layers means more expressive power regardless of activation.** With identity activations, extra layers add parameters and zero capability.
- **Confusing the activation with the activation function, or with the loss.** $g$ is the function; the activation is the number it returns. The loss and cost functions live at the end of the graph, not inside the neuron.
- **Writing $a_2$ where $a^{[2]}$ is meant.** Subscripts index units within a layer; superscripts in brackets index layers.
- **Adding local derivatives along a chain, or multiplying them across parallel paths.** Both are the correct rule applied in the wrong place.
- **Believing sigmoid outputs are the prediction.** 0.84 is a probability-like score; the label comes from the 0.5 threshold.
- **Assuming ReLU is preferred because it is bounded.** It is unbounded above; the argument is its constant derivative of 1 for positive inputs.
- **Expecting backprop to choose architecture or replace the optimizer.** It does neither. It also does not do random search.
- **Taking "networks mimic the brain" literally.** It was the historical motivation, not a description of what today's networks do or a workable engineering plan.

**How to approach the questions**

1. For any activation question, ask what the *derivative* does across many layers. Most of the sigmoid-versus-ReLU distractors are true-sounding statements about the outputs; the marked answer is almost always about the gradient.
2. For notation questions, decode the symbol before reading the options: bracketed superscript = layer, subscript = unit, $z$ = pre-activation, $a$ = post-activation.
3. When a question puts several derivatives along one dependency chain, the answer is their product. Count the links: five variables in a chain means five factors.
4. When a variable reaches the output through more than one route, look for the option that *sums* the per-path products. Options that multiply everything together, or that sum first and then multiply, are the standard distractors.
5. For "why does this scale" questions about the backpropagation algorithm, the answer is reuse of stored intermediate derivatives, never a claim about fewer parameters or no loss function.
6. For scaling-with-data scenarios, the expected outcome is that the large network keeps improving while the simpler model plateaus.
7. Sanity-check any numeric answer against the small worked example above: the five-factor product and the layer-by-layer $\delta$ recursion must agree, because they are the same arithmetic in a different order.

**Where this leads**: this is the final lesson of **Calculus**, and it closes the loop the course opened with limits. Every mechanism in modern deep learning — automatic differentiation frameworks, weight initialisation schemes, batch normalisation, residual connections, the Adam optimiser — is an engineering response to a property of the product of local derivatives you have just computed by hand. When you meet those in the machine-learning track, read them as answers to the question this lesson posed: what happens to a product of many small numbers as the graph gets deeper.
