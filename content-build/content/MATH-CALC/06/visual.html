1. Chain Rule To Graph

Chain Rule and Implicit differentiation already gives you dL/dw = dL/dy · dy/dz · dz/dw. A computational graph is that same sentence drawn as boxes, with one easy local derivative written on each arrow. Drag the weight and the input and watch every edge, the product, and an independent numerical check move together. Like gearing on a bike: each cog multiplies the one before it, and the ratio at the wheel is the product of them all.

Every node here is deliberately trivial — a linear function or a sigmoid — so each local derivative is a one-liner. That is the whole design of a computational graph: make the pieces boring so the composition is mechanical. The same graph with log loss instead of square loss collapses even further, to the famous dL/dw = x(ŷ − y).

2. Linear Stack Collapses

A layer is â[l] = g(W[l] · a[l-1] + b[l]). Stack five of them, then choose g. With the identity the whole stack is provably one straight line however deep you go; switch g and the same weights bend. Like stacking magnifying glasses: five in a row still just scale, until you slip one prism into the pile.

This is why the question "what if every neuron uses a linear activation?" has one answer: the network collapses to an equivalent single linear model. Depth without non-linearity buys parameters and zero expressive power — and note it is not a claim about training difficulty, it is an algebraic identity you can write down.

3. Activation Zoo

Four functions, one question each time: what does the derivative do, because backpropagation multiplies one per layer. Pick a function, drag z, and read the decay strip — the gradient factor surviving after n layers. Like photocopying a photocopy: at 25% fidelity a tenth-generation copy is blank, at 100% it is still the original.

Two of these are output-layer decisions, not hidden-layer ones. Softmax is for multi-class problems where each input belongs to exactly one of several mutually exclusive classes; a single sigmoid plus a 0.5 threshold is the binary case; linear is for an unbounded regression target. ReLU belongs in the hidden layers, and the decay strip is the reason.

4. Two Paths, One Sum

When one variable reaches the output by more than one route — which is every hidden unit in every network — the chain rule on graphs adds the path products. Compare the correct rule against the two standard distractors, with a finite-difference referee that cannot be argued with. Like two roads to the same town: you multiply the legs of each road, then add the roads.

Products run along a path, sums run across paths. Keep the two directions straight and the whole of backpropagation is bookkeeping: a hidden unit feeding forty units in the next layer contributes forty path products, added, and the network gets the same answer forty times faster than differentiating the composed formula by hand.

5. Backprop Layer By Layer

A two-layer network, all the way through: forward to a loss, then backward with the intermediate derivatives cached. The five-factor product and the layer-by-layer recursion are the same arithmetic in a different order, and the counter shows why the order matters at depth. Like doing the shopping once for the whole street instead of each neighbour driving to the same shop.

Backpropagation produces the gradient of the loss for every weight and bias, and stops there. It does not update anything, it does not search randomly, and it does not decide how many layers you should have — gradient descent, with its learning rate, is the separate step that consumes what this produces.
