**The big idea**: this is the first lesson of the course, so the ground it stands on is your own. Recall from **calculus** that the chain rule $\frac{d}{dx}f(g(x)) = f'(g(x))\,g'(x)$ takes for granted an object you differentiate constantly but rarely stop to inspect — the composite itself. Recall from **linear algebra** that applying $B$ and then $A$ is the single map $AB$, that reversing the order gives a different map, and that $A^{-1}$ exists only when the map is injective. Recall from **Python** that `f(g(x))` evaluates `g` first, and that a fitted scaler ships an `inverse_transform` for exactly the reason this lesson exists. Precalculus states all of that for one function of one real variable, and three ideas carry it. **Composing** functions wires one machine's output into the next machine's input, so order and domains are part of the model rather than bookkeeping. A function is invertible precisely when it is one-to-one, which is why **restricting** its **domain** can manufacture an inverse that did not exist a moment earlier. And **verifying** an **inverse** is a round trip taken in both directions — never a resemblance between two formulas.

**Key concepts**

- **A composite feeds output into input, and the notation reads right to left.** $(f \circ g)(x) = f(g(x))$ means: run $g$ on $x$, hand the result to $f$. Mechanically, substitute the entire expression $g(x)$ into every slot where $f$'s input appears. A heater warms a room as $T(m) = 2m + 60$ (minutes to degrees) and energy cost depends on temperature as $E(T) = 0.5T - 10$, so $E(T(m)) = 0.5(2m + 60) - 10 = m + 30 - 10 = m + 20$. Check at $m = 20$: $T = 100$ and $E = 0.5(100) - 10 = 40$, while $m + 20 = 40$. ✓ Adding the two formulas instead would give $2.5m + 50$, which measures nothing in the problem — the composite is the only combination whose units survive, and its meaning is always "the outer quantity as a function of the inner variable". That is why $C(q(h))$, with $q(h) = 50h$ units per hour and $C(q) = 10q + 500$ dollars per unit batch, is total production cost as a function of hours: $C(q(h)) = 10(50h) + 500 = 500h + 500$.
- **The outer function is whatever happens last, so the order of the story fixes the order of the formula.** A store takes 20% off with $D(p) = 0.80p$ and then adds 5% tax with $T(x) = 1.05x$, so the price paid is $T(D(p)) = 1.05(0.80p) = 0.84p$. Here $D(T(p)) = 0.84p$ as well, because two pure scalings commute — a coincidence about these functions, not a rule. It dies the instant either step adds a constant: with a \$2 handling fee $H(x) = x + 2$, $H(D(p)) = 0.80p + 2$ but $D(H(p)) = 0.80p + 1.60$. Composition is not commutative, so read the process, not the alphabet.
- **Composing is also a type check.** With $C(F) = \frac{5}{9}(F - 32)$ mapping Fahrenheit to Celsius and $K(C) = C + 273$ mapping Celsius to Kelvin, the Fahrenheit-to-Kelvin converter is $K(C(F))$: the inner function must produce what the outer function consumes. $C(K(F))$ feeds a Fahrenheit number to a machine expecting Kelvin — arithmetic happens, meaning does not. Formally the domain of $f \circ g$ is the set of $x$ in the domain of $g$ whose output $g(x)$ lands in the domain of $f$; for $f(u) = \sqrt{u}$ and $g(x) = x - 3$ that is $x \ge 3$.
- **Modeling with a composite: substitute the whole inner expression, then simplify — the outer operation hits the coefficient too.** A spill's radius grows as $r(t) = 4t$ and its area is $A(r) = \pi r^2$, so $A(r(t)) = \pi(4t)^2 = 16\pi t^2$. Squaring only the $t$ gives $4\pi t^2$ and understates the spill fourfold: at $t = 3$ hours the area is $144\pi \approx 452$, not $36\pi \approx 113$. Every non-linear outer function does this; only the identity and pure additions let a coefficient pass through untouched.
- **Read a linear model by asking what happens at zero.** In the taxi fare $f(x) = 3 + 2x$ with $x$ in miles, the 3 is the fixed initial fee charged before any miles are driven, because $f(0) = 3$, and the 2 is the charge added per additional mile. The fare after exactly one mile is $f(1) = 5$, which is neither of those numbers — a favourite distractor, and the same intercept-versus-slope reading you run on any one-feature regression.
- **Invertible means one-to-one, and nothing else.** An inverse must send each output back to *the* input that produced it, so if two inputs share an output there is no single-valued return trip. For $f(x) = x^2$ on all of $\mathbb{R}$, $f(3) = f(-3) = 9$, so $f^{-1}(9)$ would have to be both 3 and $-3$. Continuity is not the criterion, linearity is not the criterion, and "increasing everywhere" is not it either — that is sufficient but not necessary, since $f(x) = -x$ decreases everywhere and inverts perfectly.
- **The horizontal line test is injectivity drawn.** If any horizontal line $y = c$ meets the graph more than once, two inputs share the output $c$ and the function is not one-to-one. Keep it apart from the vertical line test, which answers the different question of whether a graph is a function at all. The parabola $y = x^2$ fails at every height $c > 0$; the cubic $y = x^3$ passes at every height. Reflection explains the pairing: inverting reflects the graph across $y = x$, which swaps horizontal and vertical, so a graph that fails the horizontal test reflects into something that fails the vertical one — a relation, not a function.
- **Restricting the domain manufactures invertibility, and the branch is your choice.** On $x \ge 0$, $x^2$ is strictly increasing, passes the horizontal line test, and inverts to $f^{-1}(x) = \sqrt{x}$; keep $x \le 0$ instead and the same rule inverts to $-\sqrt{x}$. Both are legitimate, and the principal-root convention is why $x \ge 0$ is the default. Restrictions that fail do so for one concrete reason — a symmetric pair survives: $x \neq 0$ still contains 3 and $-3$, $x \le 1$ still contains $-1$ and 1, and all of $\mathbb{R}$ is the original problem. Inverting swaps the two sets: $\sqrt{\ }$ has domain $x \ge 0$, which was the *range* of the restricted square, and range $y \ge 0$, which was its domain.
- **Verifying an inverse is a two-sided round trip.** Two functions are inverses when $(f \circ g)(x) = x$ **and** $(g \circ f)(x) = x$ on suitable domains — the identity function in both directions. With $f(x) = 3x$ and $g(x) = x/3$: $g(f(7)) = g(21) = 7$, and in general $f(g(x)) = 3(x/3) = x$. With $f(x) = x + 5$ and $g(x) = x - 5$: $f(g(x)) = (x - 5) + 5 = x$. What verifies nothing is an identical graph (that says $f = g$), equal slopes, or $f(x) = g(x)$ for all $x$. "On suitable domains" is load-bearing: for $f(x) = x^2$ and $g(x) = \sqrt{x}$ we get $f(g(x)) = x$ for every $x \ge 0$, but $g(f(x)) = |x|$, which equals $x$ only when $x \ge 0$ — the restriction is what turns the pair into a genuine one.
- **To find an inverse, undo the operations in reverse order.** For $f(x) = 2x - 1$, write $y = 2x - 1$, solve for $x$ to get $x = (y + 1)/2$, then rename: $f^{-1}(x) = (x + 1)/2$. $f$ multiplies then subtracts, so its inverse adds then divides. Verify both ways: $f(f^{-1}(x)) = 2 \cdot \frac{x+1}{2} - 1 = x$ and $f^{-1}(f(x)) = \frac{(2x - 1) + 1}{2} = x$. ✓ The distractor $(x-1)/2$ unwraps in the wrong order and dies at one number: it sends 1 to 0, and $f(0) = -1 \neq 1$.
- **$f^{-1}$ is notation, not an exponent.** For the restricted square $f^{-1}(x) = \sqrt{x}$, while $1/f(x) = 1/x^2$. At $x = 9$ those are 3 and $1/81$ — the reciprocal is never the inverse function unless the function happens to be its own reciprocal.

**Rules to remember**

- $(f \circ g)(x) = f(g(x))$: the inner function runs first, and the outer function is whatever the story does last.
- Substitute the whole inner expression, coefficient included, then simplify: $\pi(4t)^2 = 16\pi t^2$.
- Composition is not commutative. When two orders do agree, that is a fact about those particular functions.
- The domain of $f \circ g$ drops every $x$ whose $g(x)$ falls outside the domain of $f$.
- In $y = b + mx$, $b$ is the value at zero — the fixed part — and $m$ is the per-unit rate.
- Invertible $\iff$ one-to-one on the domain in question. That is the horizontal line test, not the vertical one.
- Restrict to a single monotone branch and an inverse exists; which branch you keep is a decision.
- Inverting swaps domain and range and reflects the graph across the line $y = x$.
- Confirm a candidate inverse with both round trips: $f(g(x)) = x$ and $g(f(x)) = x$.
- $f^{-1}$ never means $1/f$.

**Common pitfalls**

- Adding or multiplying the two formulas instead of substituting one into the other.
- Reversing the order — writing $C(K(F))$ for a Fahrenheit-to-Kelvin conversion, or $D(T(p))$ when tax comes last.
- Squaring only the variable: $A(4t) = 16\pi t^2$, never $4\pi t^2$.
- Reading the fixed fee as the cost of the first unit. Evaluate at zero, not at one.
- Calling a function invertible because it is continuous, smooth, or a nice formula. Only injectivity counts.
- Using the vertical line test to decide invertibility; it decides whether you have a function at all.
- Restricting to a domain that still contains a symmetric pair, such as $x \neq 0$ or $x \le 1$ for $x^2$.
- Forgetting the other branch: on $x \le 0$ the inverse of $x^2$ is $-\sqrt{x}$.
- Checking one direction of the round trip and declaring victory.
- Treating $f^{-1}$ as a reciprocal, or as an instruction to solve $f(x) = 0$.

**How to approach the questions**

1. For "what does this composition represent", follow the units: the inner variable is the input, the outer quantity is the output, so $C(q(h))$ is dollars as a function of hours. Distractors usually describe the *inverse* relationship instead.
2. When a scenario describes two steps in sequence, write the second step as the outer function and the first as the inner. Then sanity-check by feeding one number through by hand.
3. To build a composite formula, substitute the inner expression in full, then simplify — and look specifically at what happens to its coefficient under the outer operation.
4. For invertibility, hunt for two inputs sharing an output. Finding one pair settles the question instantly; failing to find one is the horizontal line test passing.
5. For a proposed inverse, test a single easy number in both directions. $f(g(2))$ and $g(f(2))$ eliminate three distractors faster than any algebra.
6. When a restriction is offered, check it contains no symmetric pair and that the function is monotone on it — then read off which branch of the inverse that choice selects.
