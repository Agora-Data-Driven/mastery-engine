### Composing functions and modeling

- Q: A factory produces q(h) = 50h units in h hours, and the cost to produce q units is C(q) = 10q + 500. What does the composition C(q(h)) represent?
    [CORRECT] Total production cost as a function of hours
    [ ] The cost of one single produced unit
    [ ] Units produced for a given cost amount
    [ ] Hours needed to reach a target cost
- Q: A taxi fare is modeled by f(x) = 3 + 2x, where x is the number of miles traveled. What does the 3 represent?
    [ ] The total number of miles in the trip
    [CORRECT] The fixed initial fee charged before any miles
    [ ] The total fare after exactly one mile
    [ ] The charge added for each additional mile
- Q: A heater raises room temperature over time m (in minutes) as T(m) = 2m + 60, and the energy cost depends on temperature as E(T) = 0.5T - 10. What is the energy cost as a function of m?
    [ ] E(m) = 2m + 50
    [ ] E(m) = m + 30
    [CORRECT] E(m) = m + 20
    [ ] E(m) = 0.5m + 60
- Q: Given K(C) = C + 273 (Celsius to Kelvin) and C(F) = (5/9)(F - 32) (Fahrenheit to Celsius), which composition converts Fahrenheit directly to Kelvin?
    [CORRECT] K(C(F))
    [ ] K(F) + C(F)
    [ ] C(K(F))
    [ ] K(F) - C(F)
- Q: The radius of a circular oil spill grows over time as $r(t) = 4t$, where $t$ is in hours, and the area is $A(r) = \pi r^2$. Which function gives the spill's area as a function of time?
    [ ] $A(t) = 8 \pi t^2$
    [ ] $A(t) = 16 \pi t$
    [ ] $A(t) = 4 \pi t^2$
    [CORRECT] $A(t) = 16 \pi t^2$
- Q: A store first applies a 20% discount given by D(p) = 0.80p to an original price p, and then adds 5% sales tax given by T(x) = 1.05x. Which composition gives the final price paid?
    [ ] D(p) + T(p)
    [ ] D(T(p))
    [CORRECT] T(D(p))
    [ ] D(p) * T(p)

### Invertible functions and restricting domains

- Q: Why is a domain restriction sometimes needed to invert a function such as $f(x) = x^2$?
    [ ] Because $x^2$ produces no real outputs
    [ ] Because inverting requires an odd function
    [ ] Because squaring cannot be reversed at all
    [CORRECT] Because $x^2$ is not one-to-one on all of $R$
- Q: Which restricted domain makes $f(x) = x^2$ invertible?
    [ ] $x \neq 0$
    [ ] all real numbers
    [CORRECT] $x \ge 0$
    [ ] $x \le 1$
- Q: A function has an inverse function on a given domain only if, on that domain, it is
    [ ] continuous everywhere
    [CORRECT] one-to-one (injective)
    [ ] a linear function
    [ ] increasing everywhere
- Q: Which graphical test determines whether a function is one-to-one (and therefore invertible)?
    [ ] The midpoint test
    [ ] The distance test
    [ ] The vertical line test
    [CORRECT] The horizontal line test
- Q: If $f(x) = x^2$ is restricted to the domain $x \ge 0$, what is its inverse $f^{-1}(x)$?
    [ ] $\frac{1}{x^2}$
    [ ] $x^2$
    [ ] $ - \sqrt{x} $
    [CORRECT] $\sqrt{x}$

### Verifying inverse functions

- Q: Which condition confirms that two functions f and g are inverses of each other?
    [CORRECT] (f o g)(x) = x and (g o f)(x) = x on suitable domains
    [ ] The equation f(x) = g(x) holds for every value of x
    [ ] The functions f and g share identical slopes everywhere
    [ ] The functions f and g share exactly the same graph
- Q: Let f(x) = 3x and g(x) = x/3. What is g(f(7))?
    [ ] 49/3
    [CORRECT] 7
    [ ] 7/3
    [ ] 21
- Q: Why do domain restrictions matter when checking whether a function has an inverse?
    [ ] Because only linear functions are ever able to have inverses
    [ ] Because only quadratic functions can ever possibly have inverses
    [ ] Because an inverse completely ignores all the function's outputs
    [CORRECT] Because the function must be one-to-one there to be invertible
- Q: Let f(x) = x + 5 and g(x) = x - 5. What is f(g(x))?
    [ ] 5
    [CORRECT] x
    [ ] x - 10
    [ ] x + 10
- Q: Which function is the inverse of f(x) = 2x - 1?
    [CORRECT] (x + 1)/2
    [ ] (x - 1)/2
    [ ] 1 - 2x
    [ ] 2x + 1
