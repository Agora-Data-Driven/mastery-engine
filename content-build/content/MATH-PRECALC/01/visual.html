1. Two Machines In Series

You have read a single function off a formula ten thousand times, and every chain rule you ever applied took the object on the right for granted. Drag one input and watch it run through one machine, then through two wired end to end. Like a factory line: the second station can only work on what the first one hands it.

Notation runs right to left: in (f ∘ g)(x) = f(g(x)) the machine written second runs first. That is the same convention as the matrix product AB from linear algebra — apply B, then A — and the same evaluation order Python uses for f(g(x)). Nothing new is being defined here; it is being named so you can reason about it.

2. Which Function Last

The outer function is whatever the story does last. Pick a two-step process and drag the input: both orders are computed, and you can see when they agree, by how much they differ, and when one of them is simply nonsense. Like socks and shoes: some pairs of steps you can swap, and some ruin your morning.

Composing is also a type check. The inner function must produce what the outer function consumes, which is why C(K(F)) hands a Fahrenheit number to a machine built for Celsius: arithmetic happens, meaning does not. Formally the domain of f ∘ g is the set of x in g's domain whose output g(x) lands in f's domain — for f(u) = sqrt(u) and g(x) = x − 3 that is x ≥ 3, and nothing outside it is in the composite at all.

3. Substitute The Whole Thing

An oil spill's radius grows as r(t) = k·t and its area is A(r) = pi·r². Substituting the whole inner expression is not a formality — the outer operation hits the coefficient too. Drag k and t and watch the true spill next to the one you get by squaring only the t. Like doubling a recipe: you double every ingredient, not just the flour.

The size of the mistake is not a constant — it is exactly k, the coefficient you failed to square. At k = 1 the two answers coincide and the error is invisible, which is why practising on r(t) = t teaches you nothing. Only the identity and pure additions let a coefficient through untouched; every non-linear outer function transforms it.

4. Horizontal Line Test

A function has an inverse exactly when it is one-to-one, and a horizontal line is that property drawn. Pick a rule, drag the line, and then cut the domain down until the line can never hit twice. Like a coat check: two coats on one ticket and nobody gets their coat back.

Keep this apart from the vertical line test, which answers a different question — whether the graph is a function at all. The two are linked by reflection: inverting reflects the graph across y = x, which swaps horizontal for vertical, so a graph that fails the horizontal test reflects into something that fails the vertical one. Not a function, just a relation. That reflection is visual 5.

5. The Round Trip

Two functions are inverses when both round trips hand back x — not when the formulas look alike. Pick a candidate pair, drag the test value, and watch each direction separately; one can pass while the other fails. Like a translation: English to French and back must return your sentence, both ways.

Remember what f⁻¹ is not. It is notation, never an exponent: for the restricted square f⁻¹(x) = √x while 1/f(x) = 1/x², and at x = 9 those are 3 and 1/81. Nor is it an instruction to solve f(x) = 0. The only test is the one on this panel, run in both directions.
