### Advanced rational expression arithmetic

- Q: What is the first step when adding two rational expressions that have unlike denominators?
    [ ] Add the numerators and the denominators
    [CORRECT] Find a common denominator
    [ ] Cancel any common factors first
    [ ] Invert the second fraction and multiply
- Q: Simplify $\frac{x}{x - 1} + \frac{1}{x - 1}$.
    [ ] $x + 1$
    [CORRECT] $\frac{x + 1}{x - 1}$
    [ ] $1$
    [ ] $\frac{x}{(x - 1)^2}$
- Q: Simplify 2/(x + 1) - 1/(x + 1).
    [ ] (x + 2)/(x + 1)
    [ ] 0
    [CORRECT] 1/(x + 1)
    [ ] 1/x
- Q: Why should the denominators be factored before adding or subtracting rational expressions?
    [ ] To eliminate the domain restrictions entirely
    [ ] Because a sum is always simpler than a product
    [CORRECT] To correctly identify the least common denominator
    [ ] Because unfactored denominators cannot be added

### End behavior and discontinuities (Asymptotes)

- Q: What is the vertical asymptote of f(x) = 1/(x - 2)?
    [ ] x = -2
    [ ] x = 0
    [CORRECT] x = 2
    [ ] y = 2
- Q: What is the horizontal asymptote of f(x) = (3x + 1)/(x - 4)?
    [ ] y = 1/4
    [ ] x = 3
    [ ] y = 0
    [CORRECT] y = 3
- Q: When analyzing the end behavior of a polynomial or rational function as x grows very large in magnitude, which terms dominate the behavior?
    [ ] The lowest-degree terms
    [ ] The constant terms
    [CORRECT] The leading terms
    [ ] The middle-degree terms
- Q: A rational function has a vertical asymptote at the values of x where
    [ ] the degree of the numerator exceeds the denominator
    [ ] the numerator is zero but the denominator is not
    [CORRECT] the denominator is zero and the factor does not cancel
    [ ] the denominator is zero but the same factor cancels
- Q: What feature does the graph of $f(x) = \frac{x^2 - 1}{x - 1}$ have?
    [ ] A genuine $x$-intercept where the curve actually crosses $x = 1$
    [CORRECT] A removable point discontinuity, that is a hole, at $x = 1$
    [ ] A horizontal asymptote running along the whole line $y = 1$
    [ ] A nonremovable vertical asymptote located exactly at $x = 1$

### Graphs of rational functions

- Q: Which statement best describes the graph of f(x) = 1/x?
    [ ] It consists of a single branch
    [CORRECT] It has asymptotes x = 0 and y = 0
    [ ] It crosses both coordinate axes
    [ ] It is defined at the point x = 0
- Q: When sketching the graph of a rational function, which feature should be identified first?
    [ ] The area enclosed under the curve
    [ ] The derivative at the origin
    [CORRECT] The domain restrictions and asymptotes
    [ ] The average rate of change
- Q: The x-intercepts of a rational function occur at the x-values where
    [ ] the numerator and denominator degrees match
    [CORRECT] the numerator is zero and the denominator is not
    [ ] the numerator and denominator are equal
    [ ] the denominator equals zero
- Q: For f(x) = (x - 1)/(x + 2), what is the y-intercept?
    [ ] 2
    [ ] 1/2
    [ ] -2
    [CORRECT] -1/2
- Q: For f(x) = (x - 1)/(x + 2), what is the x-intercept?
    [ ] x = -2
    [ ] x = 0
    [ ] x = 2
    [CORRECT] x = 1
