    [CORRECT] 5
    [ ] 1
- Q: At x = 3 the left-hand limit equals 4 and the right-hand limit equals 9. Then lim x->3 f(x)
    [ ] equals 13
    [CORRECT] does not exist
    [ ] equals 9
    [ ] equals 4
- Q: A limit at x = a can exist even when f(a) is undefined because
    [CORRECT] a limit reflects nearby behavior, not the value at a
    [ ] tables always reveal the exact value at a
    [ ] every undefined function still has a limit there
    [ ] graphs are required to ignore any holes
- Q: What does lim x->a f(x) describe?
    [ ] The average value of f near a
    [ ] The exact value of f(a) itself
    [ ] The slope of the graph at x = a
    [CORRECT] The value f(x) nears as x nears a
- Q: A table shows f(x) approaching 7 from both sides as x approaches 2. What is lim x->2 f(x)?
    [ ] 2
    [ ] does not exist
    [ ] 5
    [CORRECT] 7

### Limit properties and algebraic manipulation

- Q: Why is factoring useful when evaluating a limit that gives the 0/0 form on direct substitution?
    [ ] It removes the need for any substitution
    [ ] It forces every such limit to equal 0
    [CORRECT] It can cancel the common factor causing 0/0
    [ ] It permanently enlarges the domain of f
- Q: Evaluate $\lim_{x \to 3} \frac{x^2 - 9}{x - 3}$.
    [ ] $3$
    [ ] $0$
    [CORRECT] $6$
    [ ] $9$
- Q: Evaluate $\lim_{x \to 1} \frac{x^2 - 1}{x - 1}$.
    [ ] 1
    [ ] does not exist
    [CORRECT] 2
    [ ] 0
- Q: Assuming the individual limits exist, which limit property is valid?
    [ ] lim(f + g) = lim f * lim g
    [ ] lim(f / g) = lim f - lim g
    [CORRECT] lim(f + g) = lim f + lim g
    [ ] lim(c*f) = c + lim f
- Q: Evaluate $\lim_{x \to 2} (x^2 + 3x - 4)$.
    [ ] 2
    [ ] 4
    [CORRECT] 6
    [ ] 10

### Continuity and the Intermediate Value Theorem

- Q: Which function is continuous for every real number $x$?
    [CORRECT] $x^2 + 1$
    [ ] $\frac{1}{x}$
    [ ] $\frac{x - 2}{x - 2}$
    [ ] $\sqrt{x}$
- Q: For a function continuous on [a, b], what does the Intermediate Value Theorem guarantee?
    [ ] It has both a maximum and a minimum only
    [ ] It is increasing across the whole interval
    [ ] It is differentiable on the interval (a, b)
    [CORRECT] It attains every value between f(a) and f(b)
- Q: If a continuous function satisfies f(1) = -2 and f(3) = 4, what must be true?
    [ ] It is increasing on the interval [1, 3]
    [CORRECT] It has a root somewhere in (1, 3)
    [ ] It has no turning points on [1, 3]
    [ ] It is a linear function on [1, 3]
- Q: A function f is continuous at x = a if
    [ ] f(a) exists as a value, regardless of whether the limit there exists
    [CORRECT] f(a) exists, the limit of f(x) as x->a exists, and the two are equal
    [ ] the limit of f(x) as x->a exists, regardless of the value of f(a)
    [ ] the graph of f is strictly increasing at the point where x = a
- Q: At x = 2 a function satisfies lim x->2 f(x) = 5 and f(2) = 5. The function is
    [ ] undefined at 2
    [CORRECT] continuous at 2
    [ ] guaranteed differentiable at 2
    [ ] discontinuous at 2
