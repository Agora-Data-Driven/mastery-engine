- Q: Why is it useful to distinguish discrete random variables from continuous ones?
    [ ] Because continuous variables never possess a finite mean value
    [CORRECT] Because probabilities are described differently for the two types
    [ ] Because discrete variables cannot represent real-world numeric data

- Q: Which description best characterizes a continuous random variable?

    [ ] A variable that takes only discrete, separated whole-number values
    [ ] A variable whose entire probability mass sits at a single point
    [CORRECT] A variable modeled with smooth densities like the normal curve
- Q: What is the defining idea of a discrete random variable?
    [ ] It does not possess any single well-defined expected value
    [CORRECT] It takes specific values, each with attached probability
    [ ] It must always follow some standard normal distribution
    [ ] It can take on any value within a fixed continuous interval

### PMF, PDF, and CDF

- Q: Conceptually, what does a cumulative distribution function (CDF) report at an input value x?
    [ ] The amount of probability that lies strictly above x
    [ ] The rate at which the density is changing at x
    [ ] The largest outcome the variable can possibly reach
    [CORRECT] The total probability of outcomes at or below x
- Q: For a discrete random variable, what does a probability mass function (PMF) give?
    [ ] The slope of the distribution at a chosen value
    [ ] The long-run average of repeated random draws
    [CORRECT] The probability of each individual outcome value
    [ ] The probability accumulated up to a given value
- Q: To find the probability that a continuous random variable lands between two values a and b, what should you compute?
    [ ] The height of the density curve at the midpoint
    [ ] The curve's rate of change halfway between a and b
    [ ] The most frequently occurring value in that range
    [CORRECT] The area under the density curve from a to b
- Q: Which statement best captures the role of a probability density function (PDF) for a continuous variable?
    [ ] It applies only to variables taking whole-number values
    [CORRECT] It gives probability as area under the curve over an interval
    [ ] It returns the exact probability at any single point
    [ ] It must reach its highest value at the input zero
- Q: Why must the total area under a valid probability density curve equal exactly 1?
    [CORRECT] Because that total area represents the probability of all outcomes combined
    [ ] Because every valid probability density curve is shaped exactly as a rectangle
    [ ] Because computed area is only ever meaningful for a grouped frequency bar chart
    [ ] Because the area under any plotted density curve always equals its average

### Bernoulli, Binomial, Poisson, Uniform, and Normal

- Q: Which pairing correctly summarizes what the binomial and geometric models count?
    [ ] Binomial = how long until the first success; Geometric = how many successes in n trials
    [ ] Binomial = events per interval at a fixed rate; Geometric = a flat spread over a range
    [ ] Binomial = a flat spread over a range; Geometric = events per interval at a fixed rate
    [CORRECT] Binomial = how many successes in n trials; Geometric = how long until the first success
- Q: Why is the normal model so widely useful in practice?
    [CORRECT] Because many natural and sampling processes turn out to be approximately normal
    [ ] Because essentially every real-world dataset is known to follow it exactly always
    [ ] Because the normal model is valid only when the available sample size is small
    [ ] Because the normal model requires no parameters at all to be specified first
- Q: Which description matches the Poisson model?
    [CORRECT] Counts of events in fixed intervals at a constant average rate
    [ ] A procedure for comparing two independent sample groups
    [ ] A distribution used only to model sample mean values
    [ ] A flat, perfectly even spread across a bounded interval
- Q: What does a geometric model count?
    [ ] The gap between two separately computed sample averages
    [CORRECT] The number of independent trials up to the first success
    [ ] The number of successes obtained across n fixed trials
    [ ] The number of events occurring per interval at a steady rate
- Q: When is a binomial model the appropriate choice?
    [ ] When recording the continuous waiting time until the very first success occurs here
    [ ] When the per-trial success probability gradually shifts from one trial to the next one
    [ ] When describing a single random quantity that is measured on a fully continuous scale
    [CORRECT] When counting successes across a fixed number of independent equal-probability trials

### Expected Value and Variance of random variables

- Q: Why is expected value described as a weighted average rather than a plain average?
    [CORRECT] Because outcomes with higher probability count more
    [ ] Because probabilities are dropped once the sum is taken
    [ ] Because each possible outcome is given equal weight
    [ ] Because outcomes are sorted in order before averaging
- Q: What does the expected value of a random variable capture?
    [CORRECT] Its long-run average outcome over many repetitions
    [ ] The largest value the variable could ever attain
    [ ] Its single most probable outcome and nothing else
    [ ] The middle value once all outcomes are ordered
- Q: A discrete random variable takes the value 0 with probability 1/2 and the value 4 with probability 1/2. What is its expected value?
    [ ] 1
    [ ] 4
    [ ] 8
    [CORRECT] 2
- Q: Why is standard deviation often easier to interpret than variance?
    [ ] Because it disregards how spread out the data is
    [ ] Because it is always larger than the variance
    [CORRECT] Because it is reported in the variable's original units
    [ ] Because its value is always a whole number
- Q: Squaring the deviations from the mean when computing variance solves what problem?
    [ ] It guarantees the variable follows a normal law
    [ ] It removes any need to use probabilities at all
    [CORRECT] Positive and negative deviations would otherwise cancel
    [ ] It forces the mean to equal the median value
